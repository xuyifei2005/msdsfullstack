## 根本原因分析

### 1. PDF格式差异
不同的PDF文件使用了不同的章节标题格式：

- **成功解析的格式**:
  ```
  第二部分：危险性概述
  危险性类别： 第6.1类 毒害品
  ```

- **无法解析的格式**:
  ```
  可能使用了不同的标题样式
  可能没有明确的章节分隔符
  可能章节名称有变化
  ```

### 2. 章节匹配模式不够灵活
当前的`msds_parser.py`中的章节提取模式可能不够灵活：

```python
# 现有模式
rf'第\s*{i+1}\s*[章节部分][:：]\s*{re.escape(section_name)}(.*?)(?=第\s*\d+\s*[章节部分]|$)'
```

这个模式假设：
- 章节必须以"第X部分"开头
- 后面跟着冒号
- 然后是具体的章节名

但实际PDF可能使用了不同的格式。

## 解决方案

### 方案1: 增强章节匹配模式 (推荐)

修改`msds_parser.py`中的`extract_sections`方法，增加更多匹配模式：

```python
def extract_sections(self, text: str) -> Dict:
    """提取16个章节内容 - 增强版"""
    sections_content = {}
    
    for i, section_name in enumerate(self.sections):
        # 多种匹配模式
        patterns = [
            # 标准格式: "第一部分：化学品及企业标识"
            rf'第\s*{i+1}\s*[章节部分][:：]\s*{re.escape(section_name)}(.*?)(?=第\s*\d+\s*[章节部分]|$)',
            
            # 简化格式: "1. 化学品及企业标识"
            rf'{i+1}\.\s*{re.escape(section_name)}(.*?)(?=\d+\.|$)',
            
            # 直接章节名: "化学品及企业标识"
            rf'{re.escape(section_name)}[:：]?\s*(.*?)(?={"".join([re.escape(s) for s in self.sections[i+1:i+2]])}|$)',
            
            # 章节名作为标题（无编号）
            rf'(?:^|\n)\s*{re.escape(section_name)}\s*\n(.*?)(?=\n\s*(?:{"".join([re.escape(s) for s in self.sections])})|$)',
        ]
        
        # 尝试所有模式
        for pattern in patterns:
            match = re.search(pattern, text, re.DOTALL | re.IGNORECASE | re.MULTILINE)
            if match:
                content = match.group(1).strip()
                if content and len(content) > 10:
                    sections_content[section_name] = content
                    break
        
        if section_name not in sections_content:
            sections_content[section_name] = ""
            logger.warning(f"未找到章节: {section_name}")
    
    return sections_content
```

### 方案2: PDF格式标准化预处理

在提取文本后，对PDF文本进行预处理和标准化：

```python
def normalize_pdf_text(text: str) -> str:
    """标准化PDF文本格式"""
    # 1. 统一章节标题格式
    section_mappings = {
        r'化学品及企业标识': '化学品及企业标识',
        r'危险性概述': '危险性概述',
        r'成分[/／]组成信息': '成分/组成信息',
        # ... 更多映射
    }
    
    for pattern, replacement in section_mappings.items():
        text = re.sub(pattern, replacement, text, flags=re.IGNORECASE)
    
    # 2. 添加章节分隔符
    # 如果文本中没有明确的章节编号，可以尝试添加
    
    # 3. 清理多余的空白和换行
    text = re.sub(r'\s+', ' ', text)
    text = re.sub(r'\n\s*\n', '\n', text)
    
    return text
```
