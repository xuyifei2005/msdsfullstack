# MSDS PDF特定格式批量转换工具使用说明

## 概述

本工具专门用于批量转换特定格式的MSDS PDF文档为XML格式，特别针对以下类型的PDF文档：

- **目标格式**: `(1,4,5,6,7,7-六氯-8,9,10-三降冰片-5-烯-2,3-亚基双亚甲基)亚硫酸酯、1,2,3,4,7,7-hexachloro-8,9,10-trinorborn-2-en-5,6-ylenedimethyl、115-29-7.pdf`
- **输出格式**: 标准XML结构，包含16个MSDS章节
- **支持功能**: 批量处理、多线程并行、进度显示、错误重试

## 文件结构

```
pdf2xml/
├── xml_generator.py              # XML生成器（新增）

├── test_specific_format.py      # 特定格式测试脚本（新增）
├── msds_parser.py               # MSDS解析器（已优化）
├── config.py                    # 配置文件（已优化）
├── pdf_to_xml.py                # PDF转XML核心功能
├── batch_convert.py            # 通用批量转换器
└── output/                      # 输出目录
    ├── test_specific_format.xml # 测试生成的XML
    └── specific_format_conversion_report.json # 转换报告
```

## 快速开始

### 1. 单文件测试

首先测试单个PDF文件的转换：

```bash
cd pdf2xml
python test_specific_format.py
```

这将：
- 测试目标PDF文件的转换
- 显示详细的转换过程
- 生成测试XML文件
- 验证XML格式正确性

### 2. 批量转换

测试成功后，进行批量转换：

```bash
cd pdf2xml
python start_convert_specific.py
```

或者使用命令行参数：

```bash
python batch_convert_specific.py -i "输入目录" -o "输出目录" -w 4
```

## 功能特性

### 1. 智能解析

- **文件名解析**: 自动从文件名提取化学品名称、CAS号等信息
- **内容解析**: 智能识别PDF中的16个MSDS章节
- **字段提取**: 精确提取关键字段（CAS号、分子式、分子量等）
- **数据验证**: 自动验证提取数据的完整性和正确性

### 2. 批量处理

- **多线程并行**: 支持多线程并行处理，提高转换效率
- **进度显示**: 实时显示转换进度和状态
- **错误处理**: 自动处理转换错误，生成详细错误报告
- **断点续传**: 支持中断后继续转换，自动跳过已处理的文件

### 3. 输出格式

生成的XML文件包含：

```xml
<?xml version="1.0" encoding="utf-8"?>
<msds_list version="1.0" generated_at="2025-10-21T17:03:31.820289">
  <msds>
    <basic_info>
      <product_name>化学品名称</product_name>
      <product_english_name>英文名称</product_english_name>
      <cas_number>115-29-7</cas_number>
      <molecular_formula>C9H6Cl6O3S</molecular_formula>
      <molecular_weight>406.91</molecular_weight>
      <!-- 更多字段... -->
    </basic_info>
    <hazard_info>危险性概述</hazard_info>
    <component_info>成分/组成信息</component_info>
    <!-- 16个章节... -->
  </msds>
</msds_list>
```

## 输出文件

### 1. XML文件

每个PDF文件对应一个XML文件，包含完整的MSDS信息。

### 2. 转换报告

`specific_format_conversion_report.json` 包含：
- 转换统计信息
- 成功文件列表
- 失败文件列表
- 详细错误信息

### 3. 日志文件

`logs/specific_format_conversion.log` 包含详细的转换日志。

## 故障排除

### 常见问题

1. **文本提取失败**
   - 检查PDF是否为扫描版
   - 确认PDF文件未损坏
   - 检查文件路径是否正确

2. **章节解析不完整**
   - 检查PDF格式是否符合预期
   - 查看日志文件了解具体错误
   - 可能需要调整解析规则

3. **XML生成失败**
   - 检查输出目录权限
   - 确认磁盘空间充足
   - 查看详细错误日志

### 调试模式

使用详细模式获取更多信息：

```bash
python batch_convert_specific.py -i "输入目录" -o "输出目录" -v
```

## 性能优化

### 线程数设置

根据CPU核心数调整线程数：
- 4核CPU: 建议4个线程
- 8核CPU: 建议6-8个线程
- 16核CPU: 建议8-12个线程

### 内存使用

- 单个PDF文件约占用10-50MB内存
- 建议可用内存至少2GB
- 大批量处理时注意内存使用情况

## 扩展功能
