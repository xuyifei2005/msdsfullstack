**方法2: 先重命名PDF文件为简单名称**
```python
# rename_pdfs.py
import os
from pathlib import Path
import shutil

src_dir = Path(r"D:\XUYIFEI\XUPROJECTS\msdsfullstack\aboutproject\doc")
dst_dir = Path(r"D:\XUYIFEI\XUPROJECTS\msdsfullstack\aboutproject\doc\renamed")

dst_dir.mkdir(exist_ok=True)

for i, pdf in enumerate(src_dir.glob("*.pdf"), 1):
    # 从文件名提取CAS号
    cas = None
    parts = pdf.stem.split("、")
    if len(parts) >= 3:
        # 假设最后一部分包含CAS号
        import re
        match = re.search(r'(\d+-\d+-\d+)', parts[-1])
        if match:
            cas = match.group(1)
    
    # 生成新文件名
    if cas:
        new_name = f"msds_{cas}.pdf"
    else:
        new_name = f"msds_{i:04d}.pdf"
    
    shutil.copy2(pdf, dst_dir / new_name)
    print(f"复制: {pdf.name} -> {new_name}")

print(f"\n完成！已复制 {i} 个文件到 {dst_dir}")
```

## ⚠️ 已知限制和解决方案

### 限制1: 扫描版PDF无法提取文本
**解决方案**:
- 使用OCR软件预处理（Adobe Acrobat、ABBYY FineReader）
- 或集成tesseract-ocr库

### 限制2: 加密PDF无法读取
**解决方案**:
- 先解密PDF
- 或在config.py中配置密码

### 限制3: 特殊格式MSDS解析不准确
**解决方案**:
- 调整config.py中的正则表达式
- 针对特定格式定制解析规则

### 限制4: 中文文件名在Windows命令行中显示乱码
**解决方案**:
- 使用Python脚本直接处理（推荐）
- 或将文件重命名为简单的英文名

## 🎯 立即开始

### 最简单的方式（推荐）

1. **创建启动脚本** - 保存以下内容为 `start_convert.py`:

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
MSDS PDF批量转XML启动脚本
简化版本，直接运行即可
"""

import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent))

from batch_convert import BatchConverter

# 配置路径
INPUT_DIR = r"D:\XUYIFEI\XUPROJECTS\msdsfullstack\aboutproject\doc"
OUTPUT_DIR = r"D:\XUYIFEI\XUPROJECTS\msdsfullstack\pdf2xml\output"
WORKERS = 4  # 线程数

def main():
    print("=" * 60)
    print("MSDS PDF批量转XML工具")
    print("=" * 60)
    print(f"\n输入目录: {INPUT_DIR}")
    print(f"输出目录: {OUTPUT_DIR}")
    print(f"线程数: {WORKERS}\n")
    
    # 确认
    response = input("开始转换？(y/n): ")
    if response.lower() != 'y':
        print("已取消")
        return
    
    # 创建转换器
    converter = BatchConverter(
        input_dir=INPUT_DIR,
        output_dir=OUTPUT_DIR,
        max_workers=WORKERS
    )
    
    try:
        # 执行转换
        converter.convert_batch(skip_existing=True)
        
        # 显示结果
        converter.print_summary()
        
    except KeyboardInterrupt:
        print("\n\n用户中断")
        converter.print_summary()
    
    except Exception as e:
        print(f"\n错误: {e}")
        import traceback
        traceback.print_exc()

if __name__ == '__main__':
    main()
```

2. **运行**:
```powershell
cd D:\XUYIFEI\XUPROJECTS\msdsfullstack\pdf2xml
python start_convert.py
```

3. **等待完成，查看结果**
