## 💡 处理2000多个PDF的建议

### 方案1: 直接批量（推荐）
```bash
# 一次性处理所有PDF
python batch_convert.py -i "../aboutproject/doc" -o "./output" -w 8

# 优点: 简单方便
# 缺点: 如果中断需要重新开始（但会自动跳过已转换的）
```

### 方案2: 分批处理（更稳妥）
```bash
# 将2000个PDF分成4批，每批500个
# 放在4个子目录: batch1, batch2, batch3, batch4

python batch_convert.py -i "./batch1" -o "./output" -w 8
python batch_convert.py -i "./batch2" -o "./output" -w 8
python batch_convert.py -i "./batch3" -o "./output" -w 8
python batch_convert.py -i "./batch4" -o "./output" -w 8

# 优点: 可以随时中断和继续，更可控
# 缺点: 需要手动分批
```

### 性能估算
- **单个文件**: 约0.5-2秒
- **2000个文件**: 
  - 单线程: 约30-60分钟
  - 4线程: 约10-20分钟
  - 8线程: 约5-10分钟

## ⚠️ 注意事项

### 1. PDF文件要求
- ✅ 文本型PDF（可复制文本）
- ❌ 扫描版PDF（需要先OCR识别）
- ❌ 加密PDF（需要先解密）

### 2. 文件命名建议
推荐格式: `化学品名称、英文名、CAS号.pdf`

示例: `(1,4,5,6,7,7-六氯-8,9,10-三降冰片-5-烯-2,3-亚基双亚甲基)亚硫酸酯、1,2,3,4,7,7-hexachloro-8,9,10-trinorborn-2-en-5,6-ylenedimethyl、115-29-7.pdf`

### 3. 磁盘空间
- 确保有足够空间（XML约为PDF的50%大小）
- 2000个PDF（假设每个5MB）→ 约10GB
- 对应XML → 约5GB
- 建议预留: 20GB可用空间

### 4. 内存和CPU
- 建议内存: 4GB+
- 建议CPU: 4核+
- 线程数不要超过CPU核心数的2倍

## 🔧 遇到问题？

### Python未安装
访问 https://www.python.org/downloads/ 下载安装

### 依赖安装失败
```bash
# 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 转换失败
1. 查看日志: `logs/pdf_to_xml.log`
2. 查看FAQ: `FAQ.md`
3. 使用详细模式: 加 `-v` 参数

### 转换内容不完整
- 检查PDF是否为扫描版
- 检查PDF是否可正常打开
- 尝试调整`config.py`中的正则表达式
