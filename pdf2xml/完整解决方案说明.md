## 🗄️ 数据库支持

### 支持的表结构（基于dataupdates_ok.sql）
- ✅ `msds_main` - 主表（化学品企业标识）
- ✅ `msds_hazard` - 危险性概述
- ✅ `msds_component` - 成分组成
- ✅ `msds_first_aid` - 急救措施
- ✅ `msds_fire_fighting` - 消防措施
- ✅ `msds_leak_response` - 泄漏应急
- ✅ `msds_handling_storage` - 操作储存
- ✅ `msds_exposure_control` - 接触控制
- ✅ `msds_physical_chemical` - 理化特性（30+字段）
- ✅ `msds_stability_reactivity` - 稳定性
- ✅ `msds_toxicological` - 毒理学
- ✅ `msds_ecological` - 生态学
- ✅ `msds_disposal` - 废弃处置
- ✅ `msds_transportation` - 运输信息
- ✅ `msds_regulatory` - 法规信息
- ✅ `msds_other_info` - 其他信息

**总计**: 1个主表 + 15个关联表 = 16个表

### 字段映射（100+个字段）
所有字段都基于您提供的`dataupdates_ok.sql`注释进行映射：
- 化学品CAS号 → `cas_number`
- 技术说明书编码 → `msds_code`
- 中文名称 → `product_name`
- 供应商名称 → `company_name`
- 危险性类别 → `hazard_category`
- ... （详见《数据库导入使用指南.md》）

## 🚀 三种使用方式

### 1. 一键式（最简单）⭐ 推荐
```powershell
python pdf_to_database_full_workflow.py \
  -i ../aboutproject/doc \
  -o ./output \
  --password your_password
```

### 2. 分步执行（更灵活）
```powershell

python batch_convert.py -i ../aboutproject/doc -o ./output -w 4

# 步骤2: XML → 数据库
python batch_import_to_database.py -i ./output --password your_password
```

### 3. 仅PDF转XML（不导入数据库）
```powershell
python start_convert.py
```

```sql
-- 查看导入数量
SELECT COUNT(*) FROM msds_main;

-- 查看数据完整性
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN product_name IS NOT NULL THEN 1 ELSE 0 END) as has_name,
    SUM(CASE WHEN cas_number IS NOT NULL THEN 1 ELSE 0 END) as has_cas
FROM msds_main;

-- 查看关联表数据
SELECT 
    m.product_name,
    m.cas_number,
    COUNT(DISTINCT c.id) as components,
    COUNT(DISTINCT h.id) as hazards,
    COUNT(DISTINCT p.id) as physical_props
FROM msds_main m
LEFT JOIN msds_component c ON m.id = c.msds_id
LEFT JOIN msds_hazard h ON m.id = h.msds_id
LEFT JOIN msds_physical_chemical p ON m.id = p.msds_id
GROUP BY m.id
LIMIT 20;
```

## 🛠️ 常见问题处理

### Q1: 中文文件名乱码
**解决**: 使用`start_convert.py`或`pdf_to_database_full_workflow.py`

### Q2: 数据库连接失败
**解决**: 检查密码、主机、端口配置

### Q3: PDF解析不准确
**解决**: 
1. 检查是否为扫描版PDF（需要OCR）
2. 调整`config.py`中的正则表达式
3. 查看解析日志找出问题

### Q4: 部分字段为空
**解决**: 
1. 正常情况（PDF本身缺少数据）
2. 解析规则需要优化（修改`xml_to_database.py`）
