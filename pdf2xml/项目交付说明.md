## 🚀 三种使用方式

### 方式1: 最简单 - 直接运行（推荐）

```powershell

cd D:\XUYIFEI\XUPROJECTS\msdsfullstack\pdf2xml

# 2. 安装依赖（首次运行）

```

**优点**: 
- ✅ 最简单，一条命令搞定
- ✅ 自动处理中文文件名
- ✅ 友好的交互界面
- ✅ 可随时中断和继续

### 方式2: 命令行方式

```powershell
# 单文件转换
python pdf_to_xml.py -i "输入.pdf" -o "输出.xml"

# 批量转换
python batch_convert.py -i "PDF目录" -o "输出目录" -w 4
```

**优点**: 
- ✅ 灵活，可自定义参数
- ✅ 适合脚本化调用
- ✅ 支持更多选项

### 方式3: 批处理脚本

```powershell

# Linux/Mac
./test_convert.sh     # 测试单个文件

```

**优点**: 
- ✅ 双击即可运行
- ✅ 适合不熟悉命令行的用户

## ⚙️ 核心功能

### 1. PDF文本提取
- 使用 `pdfplumber` 库
- 支持多页PDF
- 自动处理文本编码

### 2. MSDS信息解析
- **基本信息提取**:
  - 化学品名称（中文/英文）
  - CAS号
  - 分子式/分子量
  - 别名
  - 制造商/供应商

- **章节内容提取**:
  - 16个标准MSDS章节
  - 智能章节识别
  - 多种格式适配

- **文件名辅助**:
  - 从文件名提取信息

- 格式化输出

### 4. 批量处理
- 多线程并行
- 进度条显示
- 错误重试
- 自动跳过已转换文件

### 5. 质量控制
- 数据完整性验证

- 详细错误日志
- 转换报告生成

## ⚠️ 重要注意事项

### 1. 文件类型要求
✅ **支持**: 文本型PDF（可复制粘贴文本）
❌ **不支持**: 扫描型PDF（需要先OCR识别）
❌ **不支持**: 加密PDF（需要先解密）

### 2. 文件命名建议
**推荐格式**: `化学品名称、英文名、CAS号.pdf`
- 工具会从文件名提取信息
- 作为PDF内容的补充
- 提高数据完整性

### 3. 系统资源
**最低要求**:
- CPU: 2核
- 内存: 4GB
- 磁盘: 20GB可用空间

**推荐配置**:
- CPU: 4核+
- 内存: 8GB+
- 磁盘: 50GB可用空间（SSD更佳）

### 4. 中断和恢复
- ✅ 可随时按Ctrl+C中断
- ✅ 已转换的文件会保存
- ✅ 再次运行会自动跳过已转换的文件
- ✅ 支持增量更新

## 🔧 高级配置

### 调整线程数
编辑 `start_convert.py`:
```python
WORKERS = 8  # 改为8线程
```

### 自定义解析规则
编辑 `config.py` 中的 `FIELD_PATTERNS`:
```python
FIELD_PATTERNS = {
    'chemical_name_cn': [
        r'产品名称[:：]\s*([^\n]+)',  # 添加新模式
        # ... 其他模式
    ]
}
```

### 修改XML格式
编辑 `xml_generator.py` 中的 `build_xml_tree` 方法
