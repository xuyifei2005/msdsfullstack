### XML文件格式
每个PDF生成一个对应的XML文件，文件名相同，扩展名为`.xml`

### XML结构
```xml
<?xml version="1.0" encoding="utf-8"?>
<msds_list>
  <msds>
    <!--第一部分：化学品及企业标识-->
    <basic_info>
      <cas_number>CAS号</cas_number>
      <product_name>化学品名称</product_name>
      ...
    </basic_info>
    
    <!--第2部分：危险性概述-->
    <hazard_info>
      <hazard_category>危险类别</hazard_category>
      <exposure_routes>侵入途径</exposure_routes>
      ...
    </hazard_info>
    
    <!-- 其他14个章节 -->
  </msds>
</msds_list>
```

## 🔍 质量检查建议

### 自动检查
转换完成后，程序会生成转换报告：
```
pdf2xml/output/specific_format_conversion_report.json
```

报告包含：
- 成功转换的文件列表
- 每个文件的章节完整度
- 失败文件的错误信息

### 人工抽查建议
1. 随机抽取5-10个XML文件
2. 对比原始PDF，检查关键信息：
   - CAS号是否正确
   - 化学品名称是否完整
   - 急救措施是否齐全
   - 危险性描述是否准确

## 🛠️ 故障排除

### 问题1: 转换失败
**现象**: 某个PDF转换失败  
**解决**: 
1. 检查PDF是否损坏
2. 确认PDF是否为扫描版（当前不支持）
3. 查看日志文件获取详细错误信息

### 问题2: 数据不完整
**现象**: XML中某些字段为空  
**解决**:
1. 打开原始PDF，检查是否确实有该数据
2. 如果PDF中有数据，可能需要调整提取规则
3. 查看转换报告中的章节完整度

### 问题3: 中文乱码
**现象**: XML中出现乱码  
**解决**:
1. 确认使用UTF-8编码打开XML文件
2. 检查PDF源文件编码
3. 使用支持UTF-8的文本编辑器
