

#### Windows用户

### 2. 命令行使用

```bash

python batch_convert_specific.py -i "输入目录" -o "输出目录" -w 4

python batch_convert_specific.py -i "输入目录" -o "输出目录" -v

# 不跳过已存在文件
python batch_convert_specific.py -i "输入目录" -o "输出目录" --no-skip
```

## 🛠️ 故障排除

### 常见问题

1. **文本提取失败**
   - 检查PDF是否为扫描版
   - 确认PDF文件未损坏
   - 查看详细错误日志

2. **章节解析不完整**
   - 检查PDF格式是否符合预期
   - 可能需要调整解析规则
   - 查看转换报告了解详情

3. **XML生成失败**
   - 检查输出目录权限
   - 确认磁盘空间充足
   - 查看日志文件获取详细信息

```bash
python batch_convert_specific.py -i "输入目录" -o "输出目录" -v
```
