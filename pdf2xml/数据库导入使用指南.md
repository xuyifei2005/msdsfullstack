# MSDS XML数据库导入使用指南

## 📋 功能说明

本工具提供将PDF转XML后的数据导入到MSDS管理系统数据库的完整解决方案，包括：

1. **PDF → XML转换** (`pdf_to_xml.py`, `batch_convert.py`)
2. **XML → 数据库导入** (`xml_to_database.py`)  
3. **批量数据库导入** (`batch_import_to_database.py`)

## 🚀 快速开始

### 完整流程（PDF → 数据库）

```powershell
# 1. PDF转XML
python batch_convert.py -i ../aboutproject/doc -o ./output -w 4

# 2. 安装MySQL依赖
pip install mysql-connector-python

# 3. 导入单个XML测试
python xml_to_database.py -i ./output/test.xml --password your_password

# 4. 批量导入所有XML
python batch_import_to_database.py -i ./output --password your_password
```


```powershell

  -i ./output/test.xml \
```

#### 3.1 基本用法
```powershell
python batch_import_to_database.py -i <XML目录> --password <数据库密码>
```

#### 3.2 完整参数
```powershell
python batch_import_to_database.py \
  -i ./output \
  --host localhost \
  --port 3306 \
  --user root \
  --password your_password \
  --database msds_management
```

#### 3.3 导入流程
```
1. 扫描output目录下的所有XML文件
2. 检查数据库中是否已存在（根据CAS号）
3. 跳过已存在的记录
4. 逐个解析XML并导入
5. 生成导入报告
```

## 🔧 高级配置

### 修改数据库配置

编辑 `xml_to_database.py` 的 `DB_CONFIG`:

```python
DB_CONFIG = {
    'host': 'localhost',      # 数据库主机
    'port': 3306,             # 端口
    'user': 'root',           # 用户名
    'password': 'your_password',  # 密码
    'database': 'msds_management', # 数据库名
    'charset': 'utf8mb4'
}
```

### 自定义字段映射

如需修改字段提取规则，编辑 `xml_to_database.py` 中的解析方法：

```python
def _parse_section_1(self, text: str) -> Dict:
    """解析第一部分：化学品及企业标识"""
    data = {}
    
    # 修改正则表达式以适应不同格式
    data['product_name'] = self._extract_field(text, [
        r'中文名称[：:]\s*([^\n]+)',
        r'产品名称[：:]\s*([^\n]+)',  # 添加新模式
    ])
    
    return data
```

## ⚠️ 注意事项

### 1. 数据完整性
- **必填字段**: CAS号、化学品名称
- 缺少必填字段的记录会导入失败
- 建议先测试单个文件

### 2. 重复数据处理
- 系统根据 `cas_number` 判断是否重复
- 重复记录会自动跳过
- 如需更新，请先删除旧记录

### 3. 事务处理
- 每个XML文件作为一个事务
- 导入失败会自动回滚
- 不影响其他文件的导入

### 4. 性能建议
```
单文件导入: 约0.5-1秒
批量导入: 约1500-2000文件/分钟
2000个XML: 约2-3分钟
```

## 🐛 故障排查

### 错误1: 数据库连接失败
```
✗ 数据库连接失败: Access denied
```
**解决**: 检查用户名和密码是否正确

### 错误2: 表不存在
```
✗ Table 'msds_management.msds_main' doesn't exist
```
**解决**: 执行 `dataupdates_ok.sql` 创建表结构

### 错误3: 缺少必填字段
```
✗ 缺少必填字段: CAS号或化学品名称
```
**解决**: 检查XML文件数据完整性，或改进解析规则

### 错误4: 字符编码问题
```
✗ UnicodeEncodeError
```
**解决**: 确保数据库使用 `utf8mb4` 字符集

## 📊 数据验证

### 导入后验证
```sql
-- 查看导入数量
SELECT COUNT(*) FROM msds_main;

-- 查看最近导入的记录
SELECT * FROM msds_main ORDER BY create_time DESC LIMIT 10;

-- 检查数据完整性
SELECT 
    COUNT(*) as total,
    SUM(CASE WHEN product_name IS NOT NULL AND product_name != '' THEN 1 ELSE 0 END) as has_name,
    SUM(CASE WHEN cas_number IS NOT NULL AND cas_number != '' THEN 1 ELSE 0 END) as has_cas
FROM msds_main;

-- 查看关联表数据
SELECT 
    m.product_name,
    m.cas_number,
    CASE WHEN h.id IS NOT NULL THEN '✓' ELSE '✗' END as has_hazard,
    CASE WHEN p.id IS NOT NULL THEN '✓' ELSE '✗' END as has_physical,
    CASE WHEN t.id IS NOT NULL THEN '✓' ELSE '✗' END as has_toxicological
FROM msds_main m
LEFT JOIN msds_hazard h ON m.id = h.msds_id
LEFT JOIN msds_physical_chemical p ON m.id = p.msds_id
LEFT JOIN msds_toxicological t ON m.id = t.msds_id
LIMIT 20;
```
