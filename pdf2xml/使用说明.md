## 详细使用说明

### 一、环境准备

#### 1.1 系统要求
- **操作系统**: Windows 10/11, Linux, macOS
- **Python版本**: 3.8 或更高
- **磁盘空间**: 建议至少10GB可用空间（用于存储XML文件）
- **内存**: 建议至少4GB

#### 1.2 安装Python（如果未安装）

**Windows:**
1. 访问 https://www.python.org/downloads/
2. 下载最新的Python 3.x版本
3. 安装时勾选"Add Python to PATH"

**Linux:**
```bash
sudo apt update
sudo apt install python3 python3-pip
```

**macOS:**
```bash
brew install python3
```

#### 1.3 验证安装
```bash
# 检查Python版本
python --version     # Windows
python3 --version    # Linux/Mac

# 检查pip
pip --version        # Windows
pip3 --version       # Linux/Mac
```

### 三、单文件转换

#### 3.1 基本用法
```bash
python pdf_to_xml.py -i <输入PDF路径> -o <输出XML路径>
```

#### 3.2 示例
```bash
# 示例1: 转换测试PDF
python pdf_to_xml.py -i "../aboutproject/doc/(1,4,5,6,7,7-六氯-8,9,10-三降冰片-5-烯-2,3-亚基双亚甲基)亚硫酸酯、1,2,3,4,7,7-hexachloro-8,9,10-trinorborn-2-en-5,6-ylenedimethyl、115-29-7.pdf" -o "./output/test.xml"

# 示例2: 指定输出目录（自动生成文件名）
python pdf_to_xml.py -i "input.pdf" --output-dir "./output"

# 示例3: 详细模式（显示更多日志）
python pdf_to_xml.py -i "input.pdf" -o "output.xml" -v

# 示例4: 不验证XML（加快速度）
python pdf_to_xml.py -i "input.pdf" -o "output.xml" --no-validate
```

#### 3.3 参数说明
- `-i, --input`: 输入PDF文件路径（必需）
- `-o, --output`: 输出XML文件路径（可选）
- `--output-dir`: 输出目录，自动生成文件名（可选）
- `--no-validate`: 不验证生成的XML（可选）
- `-v, --verbose`: 详细输出模式（可选）

### 四、批量转换

#### 4.1 基本用法
```bash
python batch_convert.py -i <输入目录> -o <输出目录> -w <线程数>
```

#### 4.2 示例
```bash
# 示例1: 基本批量转换
python batch_convert.py -i "../aboutproject/doc" -o "./output"

# 示例2: 使用8个线程加速
python batch_convert.py -i "../aboutproject/doc" -o "./output" -w 8

# 示例3: 重新转换所有文件（不跳过已存在的）
python batch_convert.py -i "../aboutproject/doc" -o "./output" --no-skip

# 示例4: 详细模式
python batch_convert.py -i "../aboutproject/doc" -o "./output" -v
```

#### 4.3 参数说明
- `-i, --input-dir`: 输入PDF目录（必需）
- `-o, --output-dir`: 输出XML目录（默认: ./output）
- `-w, --workers`: 并行线程数（默认: 4）
- `--no-skip`: 不跳过已存在的文件（默认会跳过）
- `-v, --verbose`: 详细输出模式（可选）

#### 4.4 批量转换流程
```
1. 扫描输入目录，查找所有PDF文件
2. 检查输出目录，跳过已转换的文件（除非使用--no-skip）
3. 使用多线程并行处理
4. 实时显示进度条
5. 生成转换报告
```

### 六、性能优化

#### 6.1 线程数设置
```bash
# CPU核心数查看
# Windows: 任务管理器 -> 性能 -> CPU
# Linux: lscpu | grep "CPU(s)"
# Mac: sysctl -n hw.ncpu

# 推荐设置
# 4核CPU: -w 4
# 8核CPU: -w 8
# 16核CPU: -w 12 (不建议超过12)
```

#### 6.2 分批处理
处理大量文件（>1000）时，建议分批：
```bash
# 方法1: 手动分批
python batch_convert.py -i "./batch1" -o "./output" -w 8
python batch_convert.py -i "./batch2" -o "./output" -w 8

# 方法2: 按日期分批
# 将不同日期的PDF放在不同子目录
```

#### 6.3 存储优化
- 使用SSD存储，速度提升2-3倍
- 确保有足够磁盘空间（XML约为PDF的50%大小）
- 定期清理日志文件

### 七、故障排除

#### 7.1 常见错误

**错误1: ModuleNotFoundError: No module named 'pdfplumber'**
```bash
# 解决: 安装依赖
pip install -r requirements.txt
```

**错误2: Permission denied**
```bash
# 解决: 检查文件权限
# Windows: 以管理员身份运行
# Linux/Mac: sudo python3 batch_convert.py ...
```

**错误3: UnicodeDecodeError**
```bash
# 解决: 确保文件名为UTF-8编码
# 或修改config.py中的编码设置
```

**错误4: 转换后内容为空**
- 检查PDF是否为扫描版（需要OCR）
- 检查PDF是否加密
- 查看日志: `logs/pdf_to_xml.log`

#### 7.2 日志查看
```bash
# 实时查看日志
# Windows
powershell Get-Content logs\pdf_to_xml.log -Wait

# Linux/Mac
tail -f logs/pdf_to_xml.log
```

#### 7.3 调试模式
```bash
# 使用详细模式查看更多信息
python pdf_to_xml.py -i "test.pdf" -o "test.xml" -v
```

### 八、高级配置

#### 8.1 自定义配置
编辑 `config.py` 修改：
- 正则表达式模式（提取字段）
- 章节名称列表
- 线程数、超时时间
- XML格式设置

#### 8.2 自定义解析规则
编辑 `msds_parser.py` 修改：
- `extract_basic_info()` - 基本信息提取
- `extract_sections()` - 章节提取
- `extract_from_filename()` - 文件名解析

#### 8.3 自定义XML格式
编辑 `xml_generator.py` 修改：
- `build_xml_tree()` - XML结构
- XML命名空间
- CDATA处理

### 九、使用技巧

#### 9.1 提高准确率
1. 使用高质量PDF（文本型而非扫描型）
2. 文件命名规范: `化学品名称、英文名、CAS号.pdf`
3. 调整正则表达式匹配规则

#### 9.2 处理特殊PDF
```python
# 加密PDF: 在config.py中设置密码
PDF_CONFIG = {
    'password': 'your_password',
    ...
}

# 扫描版PDF: 需要先OCR
# 推荐使用 Adobe Acrobat 或 ABBYY FineReader
```

#### 9.3 集成到系统
```java
// Java调用示例
ProcessBuilder pb = new ProcessBuilder(
    "python", 
    "pdf_to_xml.py", 
    "-i", pdfPath, 
    "-o", xmlPath
);
Process process = pb.start();
int exitCode = process.waitFor();
```
