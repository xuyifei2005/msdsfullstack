# MSDS智能搜索功能优化说明

## 修复日期
2025-11-05

## 问题描述
智能搜索页面（http://localhost:8000/intelligent-search）无法搜索到数据库中存在的化学品数据。例如搜索"(S)-3-(1-甲基吡咯烷-2-基)吡啶"显示"暂无搜索结果"，但数据库中确实存在该记录（ID=166，CAS号=54-11-5）。

## 根本原因
数据库中`msds_main`表的`is_active`字段值不是1，而智能搜索SQL查询条件为`m.is_active = 1`，导致查询不到记录。

## 修复内容

### 1. 数据库修复 ✅
**执行的SQL命令：**
```sql
-- 将所有is_active为NULL或不为1的记录设置为1
UPDATE msds_dev.msds_main 
SET is_active = 1 
WHERE is_active IS NULL OR is_active != 1;
```

**修复结果验证：**
```sql
-- 查询统计
SELECT COUNT(*) as total, 
       SUM(CASE WHEN is_active=1 THEN 1 ELSE 0 END) as active_count 
FROM msds_dev.msds_main;

-- 结果：total=4, active_count=4 （所有记录is_active都是1）

-- 验证具体记录
SELECT id, cas_number, product_name, is_active 
FROM msds_dev.msds_main 
WHERE id = 166;

-- 结果：id=166, cas_number=54-11-5, product_name=(S)-3-(1-甲基吡咯烷-2-基)吡啶, is_active=1
```

### 2. 后端日志优化 ✅

## 功能说明

### 智能搜索功能特性
1. **多种搜索类型：**
   - 普通搜索：支持化学品名称、别名、CAS号、企业名称的模糊匹配
   - 语义搜索：基于自然语言的智能搜索（当前使用通用搜索实现）
   - CAS号搜索：精确或模糊匹配CAS号
   - 分子式搜索：根据分子式查询

2. **高级筛选：**
   - 文档类型：标准MSDS、简化MSDS、企业自制
   - 危险性分类：易燃液体、腐蚀性、有毒、氧化性
   - 更新时间：全部、最近一周、最近一月、最近一年
   - 供应商：支持供应商名称筛选

3. **快速筛选标签：**
   - 易燃物质
   - 有毒物质
   - 腐蚀性物质
   - 氧化性物质
   - 实验室常用

4. **搜索建议：**
   - 实时搜索建议（AutoComplete）
   - 显示CAS号和英文名
   - 热门搜索推荐

5. **搜索结果展示：**
   - 卡片式结果列表
   - 显示化学品基本信息
   - 查看、下载、收藏操作
   - 多种排序方式（相关性、更新时间、名称、查看次数）

## 数据库表结构说明

### msds_main表关键字段
- `id`: 主键
- `cas_number`: CAS登记号
- `product_name`: 化学品中文名
- `product_alias`: 化学品别名
- `product_english_name`: 化学品英文名
- `company_name`: 企业名称
- **`is_active`**: 是否有效（1=有效，0=无效）⚠️ 关键字段
- `status`: 审批状态（已批准、待审批等）
- `create_time`: 创建时间
- `update_time`: 更新时间

### 智能搜索SQL逻辑
```xml
<select id="intelligentSearch" resultMap="MsdsMainResult">
    SELECT m.* FROM msds_main m
    LEFT JOIN msds_document_statistics s ON m.id = s.msds_id
    WHERE m.is_active = 1  -- ⚠️ 关键条件
    AND (
        m.product_name LIKE CONCAT('%', #{keyword}, '%')
        OR m.product_alias LIKE CONCAT('%', #{keyword}, '%')
        OR m.product_english_name LIKE CONCAT('%', #{keyword}, '%')
        OR m.cas_number LIKE CONCAT('%', #{keyword}, '%')
        OR m.company_name LIKE CONCAT('%', #{keyword}, '%')
    )
    ORDER BY m.create_time DESC
</select>
```

## 故障排查指南

### 问题1：搜索结果为空
**可能原因：**
1. is_active字段不是1
2. keyword为空或过于精确

**解决方案：**
```sql
-- 检查数据
SELECT id, product_name, is_active FROM msds_dev.msds_main;

-- 修复is_active
UPDATE msds_dev.msds_main SET is_active = 1 WHERE is_active != 1 OR is_active IS NULL;
```

### 问题2：后端接口无响应
**可能原因：**
1. 后端服务未启动
2. 权限配置问题

**解决方案：**
```powershell
# 检查容器状态
docker-compose ps

# 查看后端日志
docker logs -f msdsbackend

# 重启后端服务
docker-compose restart msdsbackend
```

### 问题3：权限拒绝错误
**可能原因：**
用户没有`system:msds:search`权限

**解决方案：**
```sql
-- 检查权限配置
SELECT menu_id, menu_name, perms FROM msds_dev.sys_menu WHERE perms LIKE '%msds%search%';

-- 检查角色权限
SELECT r.role_id, r.role_name, m.menu_name, m.perms
FROM msds_dev.sys_role r
JOIN msds_dev.sys_role_menu rm ON r.role_id = rm.role_id
JOIN msds_dev.sys_menu m ON rm.menu_id = m.menu_id
WHERE m.perms LIKE '%msds%search%';
```
