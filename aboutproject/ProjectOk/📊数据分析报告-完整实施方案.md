## 📊 示例查询SQL

### 基础统计数据API

```sql
-- GET /api/system/msds/analytics/summary
SELECT 
  (SELECT COUNT(*) FROM msds_main WHERE is_active = 1) as total_msds,
  (SELECT COUNT(DISTINCT m.id) FROM msds_main m 
   LEFT JOIN msds_hazard h ON m.id = h.msds_id 
   WHERE m.is_active = 1 AND (h.warning_word = 'danger' OR h.hazard_category LIKE '%毒害%')) as high_hazard_count,
  (SELECT COUNT(*) FROM msds_document_access_log 
   WHERE DATE_FORMAT(access_time, '%Y-%m') = DATE_FORMAT(NOW(), '%Y-%m')) as monthly_visits,
  (SELECT COUNT(DISTINCT user_id) FROM msds_document_access_log 
   WHERE access_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)) as active_users;
```

### 化学品分类分布API

```sql
-- GET /api/system/msds/analytics/category
SELECT 
  c.category_code as code,
  c.category_name as name,
  COUNT(m.id) as count,
  ROUND(COUNT(m.id) * 100.0 / (SELECT COUNT(*) FROM msds_main WHERE is_active=1), 2) as percentage
FROM msds_main m
LEFT JOIN chemical_category c ON m.category_id = c.id
WHERE m.is_active = 1
GROUP BY c.id, c.category_code, c.category_name
ORDER BY count DESC;
```

### 热门MSDS排行API

```sql
-- GET /api/system/msds/analytics/ranking?limit=10
SELECT 
  m.id,
  m.product_name,
  m.product_english_name,
  m.cas_number,
  CASE 
    WHEN h.warning_word = 'danger' THEN 'high'
    WHEN h.warning_word = 'warning' THEN 'medium'
    ELSE 'low'
  END as hazard_level,
  s.view_count,
  s.download_count,
  -- 增长率（暂时返回0，需要历史数据对比）
  0 as growth_rate
FROM msds_main m
LEFT JOIN msds_document_statistics s ON m.id = s.msds_id
LEFT JOIN msds_hazard h ON m.id = h.msds_id
WHERE m.is_active = 1
ORDER BY s.view_count DESC
LIMIT 10;
```
