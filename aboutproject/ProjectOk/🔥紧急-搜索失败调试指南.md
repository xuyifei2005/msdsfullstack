## 🔬 诊断关键点

### 情况A：看到 `[useRequest] onError 回调`
**说明：** API请求本身失败了

**可能原因：**
1. 网络连接问题
2. 后端服务未响应
3. 认证token失效

**查看信息：**
```javascript
[useRequest] onError 回调
[useRequest] 搜索错误: {...}
[useRequest] 错误详情: {
  name: "...",
  message: "...",  ← 查看这里的错误信息
  stack: "..."
}
```

**解决方案：**
- 检查Network标签的请求状态码
- 查看后端日志是否收到请求
- 检查token是否有效

### 情况B：看到 `[useRequest] onSuccess 回调` 但code不是200
**说明：** API请求成功，但业务逻辑返回错误码

**查看信息：**
```javascript
[useRequest] res.code: XXX  ← 查看这里的code值
[useRequest] res.msg: "..." ← 查看错误消息
```

**解决方案：**
- 根据code和msg判断具体问题
- 查看后端日志确认返回内容

### 情况C：code是200但仍显示失败
**说明：** 数据格式或类型转换问题

**查看信息：**
```javascript
[useRequest] res.code: 200  ← code是200
[useRequest] res.total: 1   ← total是1
[useRequest] res.rows: [...]  ← 有数据
但仍显示"搜索失败"
```

**解决方案：**
- 检查rows是否是数组
- 检查数据结构是否完整

## 💉 可能的问题和解决方案

### 问题1：Network显示404或500错误
**原因：** 后端接口路径不对或后端出错

**解决：**
```powershell
# 检查后端服务
docker logs --tail=50 msdsbackend

# 重启后端
docker-compose restart msdsbackend
```

### 问题2：Network显示401未授权
**原因：** token失效或权限不足

**解决：**
```
1. 退出登录
2. 重新登录
3. 再次测试搜索
```

### 问题3：Network显示200但前端报错
**原因：** 响应格式不匹配或拦截器处理错误

**查看Console：**
```javascript
[responseInterceptor] 响应数据: {...}
[useRequest] 搜索响应完整数据: {...}
```

### 问题4：CORS跨域错误
**症状：** Console显示CORS错误

**解决：**
```
检查后端CORS配置
或使用正确的代理配置
```

## 🆘 常见错误信息

### 错误1：`[useRequest] onError 回调`
```javascript
message: "Request failed with status code 401"
→ 认证失败，需要重新登录
```

### 错误2：`[useRequest] onError 回调`
```javascript
message: "Network Error"
→ 网络连接问题或后端服务未响应
```

### 错误3：`res.code: 500`
```javascript
[useRequest] res.code: 500
[useRequest] res.msg: "系统内部错误"
→ 后端服务器错误，查看后端日志
```

### 错误4：`res.code: 403`
```javascript
[useRequest] res.code: 403
[useRequest] res.msg: "没有权限访问该资源"
→ 权限不足
```
