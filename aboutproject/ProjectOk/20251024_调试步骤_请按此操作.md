# MSDS编辑表单数据加载 - 调试操作步骤

## 🔍 请按以下步骤操作并查看控制台输出

### 第1步：打开浏览器开发者工具
1. 打开安全智库页面（http://localhost:3000 或对应端口）
2. 按 `F12` 打开浏览器开发者工具
3. 切换到 **Console** 选项卡
4. 清空控制台日志（右键 → Clear console）

### 第2步：进入MSDS列表页
1. 登录系统
2. 导航到"MSDS管理"菜单
3. 应该能看到MSDS列表（应该有5条数据）

### 第3步：点击"16节编辑"按钮
1. 找到列表中的任意一个MSDS记录
2. 点击操作列中的 **📝 16节编辑** 按钮（<FormOutlined />图标）
3. 查看控制台输出

### 第4步：检查控制台日志

您应该看到以下日志输出（按时间顺序）：

#### 日志1：点击按钮时
```javascript

  id: 164,
  productName: "(1,4,5,6,7,7-六氯-8,9,10-三降冰片-5-烯-2,3-亚基双亚甲基)亚硫酸酯",
  casNumber: "115-29-7",
  companyName: "化学品供应商",
  ...
}
🔍 [MsdsList] record.id: 164
```

**检查**: record.id是否有值？如果没有值或undefined，这是问题所在！

#### 日志2：渲染MsdsStepForm组件
```javascript
🔍 [MsdsList] 渲染MsdsStepForm, currentRow: {id: 164, ...}
🔍 [MsdsList] 传递msdsId: 164
```

**检查**: msdsId是否为164或其他有效数字？

#### 日志3：MsdsStepForm接收参数
```javascript

```

**检查**: 是否显示此日志？如果显示"msdsId为空，跳过数据加载"，说明参数传递有问题！

#### 日志4：API响应
```javascript

  main: {code: 200, msg: "操作成功", data: {id: 164, productName: "...", ...}},
```

**检查**: 
- code是否为200？

#### 日志6：Step1表单接收数据

## 🔧 可能的问题和解决方案

### 情况A：没有看到任何日志
**问题**: 前端代码可能没有重新编译或浏览器缓存问题

**解决方法**:
1. 清除浏览器缓存（Ctrl+Shift+Delete）
2. 硬刷新页面（Ctrl+F5）
3. 重启前端开发服务器

### 情况B：显示"msdsId为空"
**问题**: currentRow.id为undefined

**解决方法**:
检查表格配置中的rowKey：
```typescript
<ProTable rowKey="id" ... />
```

确认后端返回的数据中包含id字段。

### 情况C：API返回401未授权
**问题**: Token过期或权限不足

**解决方法**:
1. 重新登录
2. 检查菜单权限配置
3. 检查后端权限注解

### 情况D：API返回200但data为空
**问题**: 数据库中没有对应数据

**解决方法**:
```sql
-- 检查数据是否存在
SELECT * FROM msds_main WHERE id = 164;
SELECT * FROM msds_hazard WHERE msds_id = 164;
```

### 情况E：数据加载成功但表单未填充
**问题**: 字段名不匹配或form未正确设置

**解决方法**:
- 检查Form.Item的name属性是否与data中的key一致
- 检查form.setFieldsValue是否被调用
- 检查是否有JavaScript错误
