## ❌ 需要补充的表和字段

### 问题1：危险等级字段缺失

**现状：**
- `msds_hazard.warning_word` 只有enum('danger','warning')
- `msds_hazard.hazard_category` 是文本描述（如"第6.1类毒害品"）
- **没有标准化的危险等级字段**（高危/中等/低危）

**解决方案A：** 在msds_main表添加hazard_level字段
```sql
ALTER TABLE msds_main 
ADD COLUMN hazard_level ENUM('low', 'medium', 'high', 'critical') 
DEFAULT 'medium' 
COMMENT '危险等级：low低危,medium中等,high高危,critical极危';

CREATE INDEX idx_hazard_level ON msds_main(hazard_level);
```

**解决方案B：** 基于hazard_category智能分类
```sql
-- 不新增字段，通过SQL逻辑判断
CASE 
  WHEN h.warning_word = 'danger' OR h.hazard_category LIKE '%毒害%' THEN 'high'
  WHEN h.warning_word = 'warning' OR h.hazard_category LIKE '%腐蚀%' THEN 'medium'
  ELSE 'low'
END as hazard_level
```

## 🆕 建议新增的表

### 表1：数据分析报告汇总表（性能优化）

**用途：** 缓存每日/每周/每月的统计数据，避免实时计算

```sql
CREATE TABLE `msds_analytics_summary` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键',
  `stat_date` DATE NOT NULL COMMENT '统计日期',
  `stat_type` VARCHAR(20) NOT NULL COMMENT '统计类型：daily日, weekly周, monthly月',
  
  -- 基础统计
  `total_msds` INT DEFAULT 0 COMMENT 'MSDS总数',
  `new_msds_count` INT DEFAULT 0 COMMENT '新增MSDS数',
  `high_hazard_count` INT DEFAULT 0 COMMENT '高危化学品数',
  `medium_hazard_count` INT DEFAULT 0 COMMENT '中危化学品数',
  `low_hazard_count` INT DEFAULT 0 COMMENT '低危化学品数',
  
  -- 访问统计
  `total_visits` INT DEFAULT 0 COMMENT '总访问量',
  `total_downloads` INT DEFAULT 0 COMMENT '总下载量',
  `total_searches` INT DEFAULT 0 COMMENT '总搜索量',
  
  -- 用户统计
  `active_users` INT DEFAULT 0 COMMENT '活跃用户数',
  `new_users` INT DEFAULT 0 COMMENT '新增用户数',
  `total_users` INT DEFAULT 0 COMMENT '总用户数',
  
  -- JSON格式的详细数据
  `category_distribution` TEXT COMMENT '分类分布JSON：{category_id: count}',
  `hazard_distribution` TEXT COMMENT '危险等级分布JSON',
  `top_msds_list` TEXT COMMENT '热门MSDS列表JSON',
  `trend_data` TEXT COMMENT '趋势数据JSON',
  
  -- 审计字段
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_date_type` (`stat_date`, `stat_type`),
  KEY `idx_stat_date` (`stat_date`),
  KEY `idx_stat_type` (`stat_type`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据分析汇总表';
```

## 📊 数据分析查询SQL汇总

### 1. 基础统计数据

```sql
-- MSDS文档总数
SELECT COUNT(*) as total_msds 
FROM msds_main 
WHERE is_active = 1;

-- 高危化学品数（基于warning_word='danger'）
SELECT COUNT(DISTINCT m.id) as high_hazard_count
FROM msds_main m
LEFT JOIN msds_hazard h ON m.id = h.msds_id
WHERE m.is_active = 1 
  AND h.warning_word = 'danger';

-- 本月访问量
SELECT COUNT(*) as monthly_visits 
FROM msds_document_access_log 
WHERE DATE_FORMAT(access_time, '%Y-%m') = DATE_FORMAT(NOW(), '%Y-%m');

-- 活跃用户数（最近30天）
SELECT COUNT(DISTINCT user_id) as active_users 
FROM msds_document_access_log 
WHERE access_time >= DATE_SUB(NOW(), INTERVAL 30 DAY);
```

### 2. 趋势分析

```sql
-- MSDS访问趋势（最近7天）
SELECT 
  DATE(access_time) as date,
  COUNT(*) as visits,
  COUNT(DISTINCT user_id) as unique_users
FROM msds_document_access_log
WHERE access_time >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY date
ORDER BY date;

-- 月度新增MSDS
SELECT 
  DATE_FORMAT(create_time, '%Y-%m') as month,
  COUNT(*) as new_count
FROM msds_main
WHERE is_active = 1
  AND create_time >= DATE_SUB(NOW(), INTERVAL 12 MONTH)
GROUP BY month
ORDER BY month DESC;
```

### 3. 分类分布

```sql
-- 化学品分类分布
SELECT 
  c.category_name,
  c.category_code,
  COUNT(m.id) as count,
  ROUND(COUNT(m.id) * 100.0 / (SELECT COUNT(*) FROM msds_main WHERE is_active=1), 2) as percentage
FROM msds_main m
LEFT JOIN chemical_category c ON m.category_id = c.id
WHERE m.is_active = 1
GROUP BY c.id, c.category_name, c.category_code
ORDER BY count DESC;
```

### 4. 危险等级分布

```sql
-- 危险等级分布（基于warning_word）
SELECT 
  CASE 
    WHEN h.warning_word = 'danger' OR h.hazard_category LIKE '%毒害%' THEN '高危'
    WHEN h.warning_word = 'warning' OR h.hazard_category LIKE '%腐蚀%' OR h.hazard_category LIKE '%易燃%' THEN '中等'
    ELSE '低危'
  END as hazard_level,
  COUNT(DISTINCT m.id) as count
FROM msds_main m
LEFT JOIN msds_hazard h ON m.id = h.msds_id
WHERE m.is_active = 1
GROUP BY hazard_level
ORDER BY FIELD(hazard_level, '高危', '中等', '低危');
```

### 5. 热门MSDS排行榜

```sql
-- 热门MSDS排行（按访问次数）
SELECT 
  m.id,
  m.product_name,
  m.product_english_name,
  m.cas_number,
  s.view_count,
  s.download_count,
  s.favorite_count,
  CASE 
    WHEN h.warning_word = 'danger' THEN '高危'
    WHEN h.warning_word = 'warning' THEN '中等'
    ELSE '低危'
  END as hazard_level,
  -- 计算增长率（需要历史数据对比）
  0 as growth_rate
FROM msds_main m
LEFT JOIN msds_document_statistics s ON m.id = s.msds_id
LEFT JOIN msds_hazard h ON m.id = h.msds_id
WHERE m.is_active = 1
ORDER BY s.view_count DESC
LIMIT 10;
```
