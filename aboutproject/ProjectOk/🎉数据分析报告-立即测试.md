### 问题1：菜单不显示"数据分析"
**检查：**
```
1. 退出登录并重新登录
2. 清除浏览器缓存
3. 检查左侧"MSDS管理"是否能展开
```

**如仍不显示：**
```sql
-- 验证菜单是否存在
docker exec msdsmysql mysql -uroot -proot_password msds_dev -e "
SELECT menu_name, path, component FROM sys_menu WHERE menu_name='数据分析';
"
```

### 问题2：页面404
**检查：**
- 前端是否成功编译
- 路由配置是否正确
- 清除浏览器缓存

**解决：**
```powershell
# 重新编译前端
docker exec msdsfrontend bash -c "cd /app && rm -rf dist && npm run build"
docker-compose restart msdsfrontend
```

### 问题3：API返回错误
**检查后端日志：**
```powershell
docker logs --tail=100 msdsbackend | findstr "analytics"
```

### 问题4：图表不显示
**检查浏览器Console：**
```
F12 → Console
查看是否有JavaScript错误
查看API请求是否成功
```
