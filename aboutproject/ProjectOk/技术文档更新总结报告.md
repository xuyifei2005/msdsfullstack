## 🔧 开发流程标准化

### 小程序开发流程
```
1. 代码编写
   └─ HBuilderX (Windows主机)
   
2. 编译运行
   └─ HBuilderX → 微信开发者工具
   
3. 调试预览
   ├─ 模拟器调试
   └─ 真机扫码预览
   
4. 后端连接
   └─ 配置WSL2局域网IP: http://192.168.x.x:8080
```

### 后端开发流程
```
1. 代码编写
   └─ Windows主机IDE (Cursor/IntelliJ IDEA)
   
2. 进入容器
   └─ docker-compose exec backend bash
   
3. 代码编译
   └─ mvn clean package -DskipTests
   
4. 服务运行
   └─ Docker容器内自动运行
   
5. 查看日志
   └─ docker-compose logs -f backend
```

### Web前端开发流程
```
1. 代码编写
   └─ Windows主机IDE (Cursor/VSCode)
   
2. 进入容器
   └─ docker-compose exec frontend bash (如有独立容器)
   
3. 安装依赖
   └─ npm install (容器内)
   
4. 开发运行
   └─ npm run dev (容器内)
   
5. 生产构建
   └─ npm run build (容器内) → Nginx容器部署
```

## 📌 关键注意事项

### ⚠️ 开发环境警告

1. **小程序开发**:
   - ⛔ 不要在Docker容器中开发小程序
   - ✅ 使用HBuilderX在Windows主机上开发
   - ✅ 编译到微信开发者工具运行

2. **后端开发**:
   - ⛔ 不要在Windows主机上直接运行Maven
   - ✅ 必须在Docker容器内编译和运行
   - ✅ 使用docker-compose exec进入容器

3. **数据库连接**:
   - ⛔ 容器内不要使用localhost连接MySQL
   - ✅ 使用容器名称：mysql:3306
   - ✅ 主机连接使用：localhost:3306

### ⚠️ 网络配置警告

1. **小程序API配置**:
   - ⛔ 不要配置为localhost（小程序无法访问）
   - ✅ 开发环境使用WSL2局域网IP
   - ✅ 生产环境使用域名

2. **跨域配置**:
   - ✅ 后端需要配置CORS允许小程序域名
   - ✅ Nginx反向代理需要配置正确的upstream
