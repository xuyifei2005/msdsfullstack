# 项目 Git 忽略规则配置

## 完成时间

2025年1月27日

## 任务描述

为整个项目配置 Git 忽略规则，避免将大文件和不必要的文件提交到版本控制系统中。

## 主要更改

1. 创建了项目根目录的 .gitignore 文件
2. 配置了以下忽略规则：

   ### Node.js 相关


   - node_modules/（依赖包目录）

   ### Docker 相关

   - msdsdocker/msds_backup_*/（Docker 备份目录）
   - msdsdocker/*.tar（Docker 镜像文件）
   - msdsdocker/msdsdata/mysql/（数据库文件）
   - msdsdocker/*.yml.bak（Docker Compose 备份）
   - msdsdocker/*.7z（压缩包）

   ### 构建输出

   - dist/
   - build/
   - target/

   ### IDE 和编辑器文件

   - .idea/
   - .vscode/
   - *.swp, *.swo

   ### 日志和数据库

   - *.log
   - *.sqlite

   ### 系统生成文件

   - .DS_Store
   - Thumbs.db

   ### 打包文件

   - *.jar, *.war, *.nar, *.ear
   - *.zip, *.tar.gz, *.rar, *.iso

   ### 临时文件

   - *.tmp
   - temp/

   ### 环境变量

   - .env
   - .env.local
   - .env.*.local

   ### 缓存目录

   - .cache/
   - .npm/

   ### 测试覆盖率

   - coverage/

   ### 备份文件

   - *.bak
   - *~

## 优化效果

1. 避免将大型二进制文件提交到 Git 仓库
2. 减少仓库体积，提高克隆和拉取速度
3. 提高 Git 操作性能
4. 防止敏感数据和临时文件泄露
5. 保持仓库整洁，只包含必要的源代码和配置文件

## 技术要点

1. 使用通配符匹配多种文件类型
2. 针对性忽略特定目录下的大文件
3. 分类管理不同类型的忽略规则
4. 保持版本控制系统的轻量级和高效性
