### 步骤1：清除浏览器缓存（必须！）

**最简单方式 - 使用无痕模式：**
```

Mac: Cmd + Shift + N

```
Windows: Ctrl + F5

## 🔍 如果搜索仍然显示"暂无搜索结果"

### 检查清单：

#### ✓ 检查1：Console输出
```
按F12 → Console标签
查看"搜索类型"是否为 general

如果显示 cas：
→ 说明浏览器缓存了旧状态
→ 使用无痕模式或清空所有浏览器数据
```

#### ✓ 检查2：Network请求
```
F12 → Network标签 → 点击搜索
找到请求：intelligent?keyword=...
查看 Query String Parameters：
- keyword: 吡啶
- searchType: general  ← 应该是 general
```

#### ✓ 检查3：后端日志
```powershell
docker logs --tail=50 msdsbackend

# 应该看到：
收到智能搜索请求 - keyword: 吡啶, searchType: general
智能搜索开始 - keyword: 吡啶, searchType: general
使用搜索类型: general
执行通用搜索: 吡啶
搜索完成 - 找到 1 条记录
```

## 🎯 重要提示

### 搜索类型和关键词必须匹配！

| 关键词类型 | 正确的搜索类型 | 示例 |
|-----------|--------------|------|
| 化学品名称（中文） | **普通搜索** | `乙醇`、`吡啶`、`(S)-3-(1-甲基吡咯烷-2-基)吡啶` |
| 化学品名称（英文） | **普通搜索** | `Ethanol`、`Pyridine` |
| CAS号 | **CAS号搜索** 或 **普通搜索** | `54-11-5`、`64-17-5` |
| 分子式 | **分子式搜索** | `C2H6O`、`CH4O` |

### ⚠️ 常见错误
```
❌ 错误：选择"CAS号"搜索，输入化学品名称
   → 用化学品名称去匹配CAS号字段 → 找不到

✅ 正确：选择"普通搜索"，输入化学品名称
   → 匹配多个字段（名称、别名、CAS号等） → 能找到
```
