## 🚀 部署步骤

### 第1步：编译后端（约3-5分钟）

```powershell
# 进入后端容器并编译
docker exec msdsbackend bash -c "cd /app && mvn clean package -DskipTests"
```

**预期输出：**
```
[INFO] BUILD SUCCESS
[INFO] Total time: XX:XX min
```

### 第2步：重启后端服务

```powershell
cd msdsdocker\msdsfullstatckcompose
docker-compose restart msdsbackend
```

**等待时间：** 约1-2分钟后端完全启动

### 第3步：编译前端（约2-3分钟）

```powershell
# 进入前端容器并编译
docker exec msdsfrontend bash -c "cd /app && rm -rf dist && npm run build"
```

**预期输出：**
```
✔ Webpack: Compiled successfully in XX.XXs
event - Build index.html
```

### 第4步：重启前端服务

```powershell
docker-compose restart msdsfrontend
```

**等待时间：** 约30秒

### 第5步：清除浏览器缓存并访问

```
1. 清除浏览器缓存（Ctrl + F5）
2. 或使用无痕模式（Ctrl + Shift + N）
3. 访问：http://localhost:8000/msds/analytics
4. 应该能看到完整的数据分析报告页面！
```
