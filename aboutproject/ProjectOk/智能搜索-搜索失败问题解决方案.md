## 🎯 问题根源（已找到）

### 核心问题：documentType筛选条件映射错误

从后端日志发现关键线索：

#### ❌ 失败的搜索（你勾选了"标准MSDS"）
```
时间: 02:01:51
请求参数: documentType: standard  ← 你勾选了"标准MSDS"
SQL条件: WHERE ... AND m.status = ?
SQL参数: standard(String)
COUNT结果: Total: 1（能统计到）
SELECT结果: Total: 0（查不到数据）
最终结果: 找到 0 条记录 ❌
```

#### ✅ 成功的搜索（不勾选任何文档类型）
```
时间: 02:01:29
请求参数: documentType: null  ← 没有勾选筛选
SQL条件: WHERE ... （没有status条件）
SELECT结果: Total: 1
最终结果: 找到 1 条记录 ✅
```

### 问题分析

1. **错误的映射逻辑：**
   ```xml
   <!-- 错误的代码（已修复） -->
   <if test="filters.documentType != null and filters.documentType != ''">
       AND m.status = #{filters.documentType}
   </if>
   ```
   - 前端发送：`documentType: 'standard'`（标准MSDS）
   - 后端映射：`m.status = 'standard'`

2. **实际数据库值：**
   ```sql
   SELECT id, status FROM msds_main WHERE id=166;
   -- 结果：id=166, status=approved
   ```
   - status字段存储的是审批状态：`approved`（已批准）
   - **不是文档类型！**

3. **SQL执行：**
   ```sql
   -- COUNT查询（分页插件）
   SELECT count(*) ... WHERE m.is_active=1 AND ... AND m.status='standard'
   -- 结果：1（为什么？可能是COUNT查询没有真正执行status条件）
   
   -- 实际SELECT查询
   SELECT m.* ... WHERE m.is_active=1 AND ... AND m.status='standard'  
   -- 结果：0（因为status='approved'，不等于'standard'）
   ```

---

## ✅ 已实施的解决方案

### 修复1：注释掉错误的documentType映射

**文件：** `MsdsSearchMapper.xml`

**修改内容：**
```xml
<if test="filters != null">
    <!-- documentType筛选暂不实现，因为msds_main表没有document_type字段 -->
    <!-- 如需实现，可以映射到其他字段或创建新字段 -->
    <!-- 已注释掉错误的status映射 -->
    
    <if test="filters.categoryId != null">
        AND m.category_id = #{filters.categoryId}
    </if>
    <if test="filters.supplier != null and filters.supplier != ''">
        AND m.company_name like concat('%', #{filters.supplier}, '%')
    </if>
    <!-- 其他筛选条件 -->
</if>
```

**效果：**
- ✅ documentType筛选条件将被忽略
- ✅ 不会添加错误的`m.status = 'standard'`条件
- ✅ 搜索能正常返回结果

## 🔬 技术细节

### 数据库字段说明

| 字段名 | 说明 | 示例值 | 用途 |
|-------|-----|--------|-----|
| `status` | 审批状态 | `approved`（已批准）| 工作流审批 |
| `is_active` | 是否有效 | `1`（有效），`0`（无效） | 软删除标记 |
| `category_id` | 化学品分类ID | 数字 | 分类筛选 |
| `company_name` | 企业/供应商名称 | 字符串 | 供应商筛选 |

**注意：**
- ⚠️ msds_main表**没有document_type字段**
- ⚠️ status字段是**审批状态**，不是文档类型
- ✅ 如需实现文档类型筛选，需要：
  1. 添加document_type字段到数据库
  2. 或基于其他业务逻辑映射

| `supplier` | `m.company_name LIKE ?` | ✅ 正常 |
