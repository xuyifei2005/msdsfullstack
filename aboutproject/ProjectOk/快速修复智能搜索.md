# 🚀 智能搜索快速修复指南

## ⚡ 一键修复脚本

在项目根目录下执行：

```powershell
cd msdsdocker\msdsfullstatckcompose
.\rebuild-frontend.ps1
```

或者完整重新编译（包括后端）：

```powershell
cd msdsdocker\msdsfullstatckcompose
.\rebuild-all.ps1
```

## 📝 手动操作步骤

### 选项A：仅重新编译前端（推荐，快速）

```powershell
# 1. 进入前端容器并编译（约2-3分钟）
docker exec -it msdsfrontend bash -c "cd /app && rm -rf dist && npm run build"

# 2. 重启前端服务
docker-compose restart msdsfrontend

# 3. 等待30秒
# 然后清除浏览器缓存（Ctrl + F5）
```

### 选项B：完整重新编译（后端+前端）

```powershell
# 1. 编译后端（约3-5分钟）
docker exec -it msdsbackend bash -c "cd /app && mvn clean package -DskipTests"

# 2. 重启后端
docker-compose restart msdsbackend

# 3. 等待2分钟后端启动

# 4. 编译前端（约2-3分钟）
docker exec -it msdsfrontend bash -c "cd /app && rm -rf dist && npm run build"

# 5. 重启前端
docker-compose restart msdsfrontend

# 6. 等待1分钟前端启动
```

## 🔍 问题排查

### 情况1：Console显示searchType是'cas'而不是'general'

**原因：** 浏览器缓存了旧的状态

**解决方案：**
```
✓ 方法1：使用无痕模式（Ctrl + Shift + N）
✓ 方法2：清空所有浏览器数据
  - 按 F12
  - Application标签
  - 右键Storage → Clear site data
✓ 方法3：换个浏览器测试
```

### 情况2：搜索结果仍然为空

**检查清单：**

```powershell
# 1. 验证数据库数据
docker exec msdsmysql mysql -uroot -proot_password msds_dev -e "SELECT id, product_name, cas_number, is_active FROM msds_main WHERE id=166;"

# 预期结果：
# id=166, product_name=(S)-3-(1-甲基吡咯烷-2-基)吡啶, cas_number=54-11-5, is_active=1

# 2. 检查后端日志
docker logs --tail=50 msdsbackend

# 应该看到：
# 收到智能搜索请求 - keyword: 吡啶, searchType: general
# 搜索完成 - 找到 1 条记录

# 3. 检查前端Network
# F12 → Network → 找到 intelligent?keyword=... 请求
# 查看 Request URL 和 Response
```

### 情况3：详情页面404错误

**检查路由配置：**
