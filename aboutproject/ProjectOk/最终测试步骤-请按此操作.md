## 🎯 问题原因（已找到并修复）

### 核心问题
**你勾选了"标准MSDS"筛选项，导致搜索失败！**

**详细分析：**
```
你的操作：
✓ 输入搜索关键词：(S)-3-(1-甲基吡咯烷-2-基)吡啶
✓ 选择搜索类型：普通搜索
✗ 勾选了"标准MSDS"  ← 这是导致失败的原因！

后端处理：
→ documentType: 'standard'
→ SQL添加条件：AND m.status = 'standard'
→ 但数据库status='approved'（已批准）
→ 所以查不到数据！❌
```

### 问题根源
- **错误的字段映射：** documentType被错误地映射到status字段
- **status字段含义：** 存储审批状态（approved/pending），不是文档类型
- **msds_main表：** 没有document_type字段

### 修复方案
✅ 已注释掉SQL中错误的documentType到status的映射  
✅ 现在documentType筛选条件会被忽略  
✅ 搜索能正常返回结果
