# Spring Boot数据源配置错误处理

## 错误时间
2025年1月27日

## 错误描述
Spring Boot应用启动失败，错误堆栈显示数据源配置相关的Bean创建失败：
```
Error creating bean with name 'druidProperties': Injection of autowired dependencies failed
```

错误链：
1. captchaController 创建失败
2. → sysConfigServiceImpl 创建失败
3. → sysConfigMapper 创建失败
4. → sqlSessionFactory 创建失败
5. → dynamicDataSource 创建失败
6. → masterDataSource 创建失败
7. → druidProperties 创建失败（根本原因）

## 错误原因
1. Druid数据源配置属性注入失败，可能的原因：
   - 缺少数据源配置文件
   - 配置文件中的属性名称错误
   - 配置文件格式错误
   - 配置文件未被正确加载

## 解决方案
1. 检查application.yml/properties文件中的数据源配置：
   ```yaml
   # 主数据源配置
   spring:
     datasource:
       druid:
         # 主库数据源
         master:
           url: jdbc:mysql://localhost:3306/ry-vue?useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=true&serverTimezone=GMT%2B8
           username: root
           password: password
           driver-class-name: com.mysql.cj.jdbc.Driver

   # 数据源类型配置
   spring.datasource.type: com.alibaba.druid.pool.DruidDataSource
   ```

2. 确保添加了必要的依赖：
   ```xml
   <!-- Druid数据源依赖 -->
   <dependency>
       <groupId>com.alibaba</groupId>
       <artifactId>druid-spring-boot-starter</artifactId>
       <version>${druid.version}</version>
   </dependency>
   ```

3. 验证数据库连接：
   - 确保MySQL服务正在运行
   - 验证数据库用户名和密码
   - 检查数据库是否存在
   - 测试端口是否可访问

4. 检查配置类：
   ```java
   @Configuration
   public class DruidConfig {
       @Bean
       @ConfigurationProperties("spring.datasource.druid.master")
       public DataSource masterDataSource(DruidProperties druidProperties) {
           DruidDataSource dataSource = DruidDataSource.class.cast(DruidDataSourceBuilder.create().build());
           return druidProperties.dataSource(dataSource);
       }
   }
   ```
