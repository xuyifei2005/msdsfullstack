# Docker 容器备份脚本修复记录

## 问题描述
在运行 `export_msds_containers.ps1` 脚本进行容器备份时，所有容器都显示为未运行状态，导致备份失败。经检查发现是容器名称匹配问题，脚本中定义的容器名称与实际运行的容器名称不一致。

## 修复内容

### 1. 更新容器名称列表
将原有的容器名称列表：
```powershell
$msdsContainers = @(
    "msdsfullstatckcompose-backend-1",
    "msdsfullstatckcompose-frontend-1", 
    "msdsfullstatckcompose-mysql-1",
    "msdsfullstatckcompose-redis-1"
)
```

更新为实际运行的容器名称：
```powershell
$msdsContainers = @(
    "msds_backend",
    "msds_frontend", 
    "msds_mysql",
    "msds_redis",
    "nginx",
    "rabbit",
    "frontend",
    "pc",
    "app",
    "upload",
    "redis",
    "mysql"
)
```

### 2. 修改镜像命名逻辑
- 原逻辑：`$imageName = "msds_exported_$($container.Replace('msdsfullstatckcompose-', '').Replace('-1', ''))"`
- 新逻辑：`$imageName = "msds_exported_$($container.Replace('msds_', '').Replace('-', '_'))"`

### 3. 修改导出文件命名逻辑
- 原逻辑：`"msds_$($container.Replace('msdsfullstatckcompose-', '').Replace('-1', ''))_image.tar"`
- 新逻辑：`"msds_$($container.Replace('msds_', '').Replace('-', '_'))_image.tar"`

## 优化效果
1. 脚本现在可以正确识别并备份所有运行中的容器
2. 导出文件命名更加规范和一致
3. 支持更多类型的容器备份（如 nginx, rabbit 等）

## 技术要点
1. 使用 PowerShell 字符串替换处理容器名称
2. 保持命名规范一致性
3. 扩展支持更多容器类型
