# MSDS智能搜索完整使用指南

## 📌 快速诊断当前问题

### 问题现象
搜索"(S)-3-(1-甲基吡咯烷-2-基)吡啶"显示"暂无搜索结果"

### 根本原因
**从后端日志分析：**
```
searchType: cas  ← 使用CAS号搜索
keyword: (S)-3-(1-甲基吡咯烷-2-基)吡啶  ← 但这是化学品名称，不是CAS号！
```

**实际情况：**
- ✅ 化学品名称：`(S)-3-(1-甲基吡咯烷-2-基)吡啶`
- ✅ 实际CAS号：`54-11-5`
- ❌ 搜索类型：`cas`（CAS号搜索）
- ❌ 搜索关键词：化学品名称（应该用CAS号）

**结论：** 用化学品名称去匹配CAS号字段，所以找不到！

## 🎯 正确的搜索方法

### 方法1：普通搜索（推荐）✅
**适用场景：** 搜索化学品名称、别名、企业名称等

1. **确保选择"普通搜索"**（标签应该是蓝色/高亮）
2. **输入化学品名称：** `(S)-3-(1-甲基吡咯烷-2-基)吡啶` 或 `吡啶`
3. **点击"搜索"按钮**
4. **预期结果：** 找到1条或多条记录

### 方法2：CAS号搜索 ✅
**适用场景：** 已知CAS号，需要精确查找

1. **点击"CAS号"标签**（标签变成蓝色）
2. **输入CAS号：** `54-11-5`（注意：这是CAS号！）
3. **点击"搜索"按钮**
4. **预期结果：** 找到1条记录

### 方法3：模糊搜索 ✅
**适用场景：** 只记得部分关键词

1. **选择"普通搜索"**
2. **输入部分关键词：** `吡啶` 或 `pyrrolidin`
3. **点击"搜索"按钮**
4. **预期结果：** 找到所有包含关键词的化学品

## 📱 智能搜索功能特性

### 四种搜索类型
| 搜索类型 | 搜索字段 | 适用场景 | 示例 |
|---------|---------|---------|------|
| **普通搜索** | 化学品名称、别名、英文名、CAS号、企业名称 | 不确定具体信息，模糊搜索 | `吡啶`、`乙醇`、`Sigma` |

| **分子式** | 分子式字段 | 已知分子式 | `C2H6O`、`CH4O` |

## 🔍 故障排查清单

### 问题1：搜索结果为空
**检查步骤：**
```
✓ 1. 确认搜索类型和关键词匹配
     - 化学品名称 → 用"普通搜索"
     - CAS号 → 用"CAS号搜索"或"普通搜索"
     
✓ 2. 检查浏览器Console
     - searchType应该是 general/cas/formula/semantic
     - keyword应该和输入的一致
     
✓ 3. 检查后端日志
     docker logs -f msdsbackend
     
✓ 4. 验证数据库数据
     docker exec msdsmysql mysql -uroot -proot_password msds_dev -e "SELECT * FROM msds_main WHERE id=166;"
```

### 问题2：搜索类型不匹配
**症状：** 界面显示"普通搜索"，但日志显示`searchType: cas`

**解决方案：**
```
1. 清除浏览器缓存（Ctrl + F5）
2. 使用无痕模式测试
3. 检查Console输出的searchType值
4. 重新编译前端代码
```

### 问题3：权限错误
**症状：** 显示"无权限访问"或401错误

**解决方案：**
```sql
-- 检查权限配置
docker exec msdsmysql mysql -uroot -proot_password msds_dev -e "
SELECT r.role_name, m.menu_name, m.perms 
FROM sys_role r
JOIN sys_role_menu rm ON r.role_id = rm.role_id
JOIN sys_menu m ON rm.menu_id = m.menu_id
WHERE m.perms LIKE '%msds%search%' AND r.role_id = 1;
"
```

### 问题4：后端服务未响应
**检查步骤：**
```powershell
# 1. 检查容器状态
docker-compose ps

# 2. 检查后端健康状态
curl http://localhost:18080/actuator/health

# 3. 查看后端日志
docker logs --tail=50 msdsbackend

# 4. 重启后端
docker-compose restart msdsbackend
```
