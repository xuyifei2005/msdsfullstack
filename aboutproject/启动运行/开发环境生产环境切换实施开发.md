# 前端开发环境！

### 不需要修改任何参数只需要运行：

开发环境启动命令已配置在 package.json 中
npm run start:dev

个命令会设置 REACT_APP_ENV=dev 和 MOCK=none。 开发环境的代理配置（在 proxy.ts 中）已经设置好了：   API请求会自动代理到后端服务：http://msdsbackend:8080  所有 /api/* 的请求会被转发到后端  头像等静态资源的 /profile/avatar/ 请求也会被正确代理   其他开发环境配置：   启用了热更新（fastRefresh）  配置了开发服务器代理  启用了调试工具和开发辅助功能   你只需要确保： Docker容器都正常运行（特别是 msdsbackend 容器）  在前端容器中运行 npm run start:dev 即可   开发环境下，前端会自动运行在开发服务器上，支持热更新，并且API请求会自动代理到后端服务。
