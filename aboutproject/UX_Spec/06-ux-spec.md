# UX Spec: MSDS 实验室管理系统 (v1.4 同步版)

## Overview
MSDS 实验室管理系统是一款专为实验室设计的化学品安全管理平台。它包含两个核心端：
- **微信小程序端**：面向科研人员，提供即时扫码、搜索、收藏和历史查阅。
- **PC 管理后台**：面向管理员，提供 Dashboard 监控、MSDS 导入、AI 智能解析、版本控制、用户管理及审计统计。

## User Flows (PC Backend)

### Flow 1: AI 智能解析录入 [v1.4 核心功能]
**Trigger:** 管理员上传 PDF 文件。
**User goal:** 自动提取 MSDS 字段，减少手动录入。

```
[AI 导入页] ──→ [选择 PDF 文件] ──→ [系统解析中]
                                          ↓
[双栏对照预览] ←── [提取 CAS, 名称, GHS, H/P 声明]
      ↓
[用户人工核对/修改低置信度字段] ──→ [确认入库]
      ↓
[保存成功] ──→ [生成唯一二维码]
```

**Steps:**
1. 用户在“AI 智能解析”页面点击上传 PDF。
2. 系统展示解析进度。
3. 界面分为左右两部分：左侧显示原 PDF，右侧显示提取出的结构化表单。
4. 系统高亮显示置信度较低的字段。
5. 用户确认无误后点击保存。

### Flow 2: 首页 Dashboard 监控 [v1.4 核心功能]
**Trigger:** 安全负责人登录系统。
**User goal:** 实时掌握实验室安全态势。

```
[Dashboard 首页] ──→ [查看核心指标 (总数, 活跃, 过期)]
                                          ↓
[监控系统性能 (CPU/内存)] ──→ [查看热门查阅排行]
```

## User Flows (Mini Program)

### Flow 1: 扫码即时查阅 (核心场景)
**Trigger:** 科研人员在实验室台架上看到试剂瓶二维码。
**User goal:** 快速了解该化学品的急救措施和危害。

```
[首页/扫码入口] ──→ [调用摄像头扫码]
                         ↓
[解析 QR 内容] ──→ [MSDS 详情页 (置顶显示 GHS 危害 & 急救)]
                         ↓
[上滑查看全文预览 (PDF)] ──→ [收藏/分享]
```

## Screens (PC Backend)

### Screen: Dashboard 仪表盘
**URL/Route:** `/dashboard`
**Purpose:** 展示系统整体运行数据。

#### Layout
```
┌─────────────────────────────────┐
│ [顶部: 统计卡片]                 │
│ [总文档数] [待审数] [查阅量] [预警] │
├─────────────────────────────────┤
│ [中间: 趋势图 (查阅趋势)]        │
├─────────────────────────────────┤
│ [左侧: 系统监控 (CPU/内存)]      │
│ [右侧: 风险品分类分布 (饼图)]    │
└─────────────────────────────────┘
```

#### States
| State | Appearance | Trigger |
|-------|------------|---------|
| Default | 实时刷新数据 | 页面加载 |
| Loading | 骨架屏 | 接口请求中 |

### Screen: AI 智能解析页
**URL/Route:** `/msds/ai-import`
**Purpose:** 利用大模型自动提取 MSDS 字段。

#### Layout
```
┌─────────────────────────────────┐
│ [左侧: PDF 预览器]               │
├─────────────────────────────────┤
│ [右侧: 结构化表单]               │
│ - 化学品基本信息 (提取结果)      │
│ - 危险性分类 (提取结果)          │
│ - H/P 声明 (提取结果)            │
├─────────────────────────────────┤
│ [底部: 人工确认并入库按钮]       │
└─────────────────────────────────┘
```

## Future Evolution Features (未来演进)

### 1. IoT 硬件联动 (Smart Cabinet)
- **UX 模式**：小程序首页增加“开启试剂柜”按钮。
- **交互**：扫码成功后，小程序显示“柜门已开启”，并实时同步库存扣减。

### 2. 危废处置全闭环 (Waste Management)
- **UX 模式**：MSDS 详情页增加“产生废弃物”入口。
- **交互**：用户录入废液量，系统自动关联 MSDS 的处置建议，并打印危废标签二维码。

## Design Notes
- **Style**: 专业、严谨、科技感。
- **PC 端**: 沿用 Ant Design Pro 风格，高密度信息展示。
- **小程序端**: 借鉴“微信安全中心”或“政务服务”风格，高对比度字体，急救信息置顶。
- **Color**: 
  - 主色: RuoYi 蓝色 (#1890FF)
  - 警示色: 危险 (红色 #f5222d), 警告 (橙色 #faad14)
