# UX Spec: MSDS 实验室管理系统

## Overview
MSDS 实验室管理系统是一款专为实验室设计的化学品安全管理平台。它包含两个核心端：
- **微信小程序端**：面向科研人员，提供即时扫码、搜索和查阅功能。
- **PC 管理后台**：面向管理员，提供 MSDS 上传、版本控制、用户管理及数据看板。

---

## User Flows (PC Backend)

### Flow 1: MSDS 上传与元数据补全
**Trigger:** 管理员收到新的化学品 MSDS 文件。
**User goal:** 将 MSDS 电子化并录入系统。

```
[MSDS 列表页] ──→ [点击上传/导入] ──→ [选择文件/拖拽]
                                          ↓
[系统预解析文件名/内容] ←── [上传中/进度条]
      ↓
[元数据编辑弹窗/页面] ──→ [手动补全/核对 CAS 等]
      ↓
[保存成功] ──→ [版本归档/自动更新最新版]
```

**Steps:**
1. 用户在“MSDS 列表”点击“导入”。
2. 系统展示上传区域，支持 PDF, DOCX 等。
3. 系统在后台解析 CAS 号和名称。
4. 用户核对自动填充的信息，补全供应商和有效期。
5. 保存后，系统将该文件标记为“最新版”。

### Flow 2: 统计看板与审计
**Trigger:** 安全负责人需要准备合规性审计报告。
**User goal:** 导出查阅日志和数据分析。

```
[统计分析看板] ──→ [选择时间范围/部门] ──→ [查看可视化图表]
                                          ↓
[审计日志页] ──→ [按 MSDS 追踪查阅记录] ──→ [一键导出审计证据包]
```

## User Flows (Mini Program)

### Flow 1: 扫码即时查阅 (核心场景)
**Trigger:** 科研人员在实验室台架上看到试剂瓶二维码。
**User goal:** 快速了解该化学品的急救措施和危害。

```
[首页/扫码入口] ──→ [调用摄像头扫码]
                         ↓
[解析 QR 内容] ──→ [MSDS 详情页 (置顶显示 GHS 危害 & 急救)]
                         ↓
[上滑查看全文预览 (PDF)] ──→ [收藏/分享]
```

## Screens (PC Backend)

### Screen: MSDS 详情编辑页
**URL/Route:** `/msds/detail/:id`
**Purpose:** 对 MSDS 的 16 部分进行结构化编辑。

#### Layout
```
┌─────────────────────────────────┐
│ [面包屑: MSDS 管理 / 详情编辑]   │
├─────────────────────────────────┤
│ [左侧: 16 部分快捷导航 (Anchor)] │
│                                 │
│ [中间: 结构化表单区域]           │
│  1. 化学品识别 (名称, CAS, 别名)│
│  2. 危险性概述 (GHS 象形图选择) │
│  3. 急救措施 (多行文本)         │
│  ...                            │
│                                 │
├─────────────────────────────────┤
│ [底部: 预览 / 保存 / 取消]       │
└─────────────────────────────────┘
```

#### States
| State | Appearance | Trigger |
|-------|------------|---------|
| Default | 表单填充已有数据 | 路由跳转至 ID |
| Loading | 全局骨架屏或 Loading 图标 | 接口拉取 16 部分数据 |
| Saving | 按钮 Loading 状态 | 点击保存 |

## Future Evolution Features (未来演进)

### 1. AI 智能解析 (AI MSDS Parser)
- **UX 模式**：上传 PDF 后，系统右侧实时展示 AI 提取结果，左侧保留原件对照。
- **交互**：低置信度字段显示“黄色波浪线”，用户点击即可在原件中定位。

### 2. IoT 硬件联动 (Smart Cabinet)
- **UX 模式**：小程序首页增加“开启试剂柜”按钮。
- **交互**：扫码成功后，小程序显示“柜门已开启”，并实时同步库存扣减。

### 3. 危废处置全闭环 (Waste Management)
- **UX 模式**：MSDS 详情页增加“产生废弃物”入口。
- **交互**：用户录入废液量，系统自动关联 MSDS 的处置建议，并打印危废标签二维码。

## Design Notes
- **Style**: 专业、严谨、科技感。
- **PC 端**: 沿用 Ant Design Pro 风格，高密度信息展示。
- **小程序端**: 借鉴“微信安全中心”或“政务服务”风格，高对比度字体，急救信息置顶。
- **Color**: 
  - 主色: RuoYi 蓝色 (#1890FF)
  - 警示色: 危险 (红色 #f5222d), 警告 (橙色 #faad14)
