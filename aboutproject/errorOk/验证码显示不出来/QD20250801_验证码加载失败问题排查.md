# 前端验证码加载失败问题排查报告

**问题类型**: 前端问题  
**问题编号**: QD20250801_验证码加载失败  
**创建时间**: 2025-08-01  
**问题状态**: 排查中  

---

## 🔍 问题描述

### 现象
- 前端登录页面验证码图片无法加载
- 后端日志显示：`No static resource captchaImage.`
- 前端请求 `/api/captchaImage` 接口失败

### 影响范围
- 用户无法正常登录系统
- 验证码功能完全失效

---

## 🔧 问题排查过程

### 1. 前端代码检查

#### 验证码请求实现
- **文件**: `/app/src/services/system/auth.ts`
- **函数**: `getCaptchaImg`
- **请求路径**: `/api/captchaImage`
- **请求方法**: GET

```typescript
export async function getCaptchaImg() {
  return request('/api/captchaImage', {
    method: 'GET',
  });
}
```

#### 登录页面调用
- **文件**: `/app/src/pages/User/Login/index.tsx`
- **调用方式**: 通过 `getCaptchaImg()` 获取验证码图片
- **显示组件**: Ant Design `Image` 组件

### 2. 代理配置检查

#### 代理规则
- **文件**: `/app/config/proxy.ts`
- **代理目标**: `http://backend:8080`
- **路径重写**: 移除 `/api` 前缀
- **配置状态**: ✅ 正常

```typescript
dev: {
  '/api/': {
    target: 'http://backend:8080',
    changeOrigin: true,
    pathRewrite: { '^/api': '' },
  },
}
```

#### 代理测试结果
```bash
# 测试命令
curl -I http://localhost:8000/api/captchaImage

# 响应头显示
x-real-url: http://backend:8080/captchaImage
```
**结论**: 代理配置正确，请求已正确转发到后端

### 3. 前端服务状态检查

#### 服务启动问题
- **问题**: 前端开发服务器无法正常启动
- **端口**: 8000端口无法连接
- **启动命令**: `npm start` / `npm run dev`

#### 启动错误分析
1. **模块解析错误**:
   ```
   Module not found: Error: Can't resolve '/app/src/.umi/umi.ts'
   ```

2. **临时文件缺失**:
   - `.umi` 目录下的临时文件丢失
   - UmiJS 构建过程异常

3. **启动过程卡死**:
   - 启动命令执行后无输出
   - 进程挂起，无法完成初始化

## 🎯 根本原因分析

### 主要问题
1. **前端开发服务器启动失败**
   - UmiJS 构建过程异常

### 次要问题
- Mock 数据被禁用 (`MOCK=none`)
- 开发环境配置可能存在问题
