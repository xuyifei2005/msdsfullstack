# 第九章理化特性数据无法显示问题解决方案

## 问题描述

在MSDS详情页面中，"第九章理化特性"章节在后端数据库中没有对应数据，但XML文件中存在理化特性数据，无法正常加载和显示数据。

## 问题排查过程

### 1. 数据库层面验证 ❌
```sql
SELECT * FROM msds_physical_chemical WHERE msds_id = 157;
```
**结果**：没有数据

### 2. XML数据验证 ✅
```xml
<physical_chemical>
  <melting_point>70～100</melting_point>
  <boiling_point>无资料</boiling_point>
  <flash_point>无资料</flash_point>
  <relative_density>1.745(20℃)</relative_density>
  <solubility>不溶于水，溶于多数有机溶剂。</solubility>
  <molecular_formula>C9H6Cl6O3S</molecular_formula>
  <molecular_weight>406.91</molecular_weight>
</physical_chemical>
```
**结果**：数据完整存在

### 3. 后端API层面验证 ✅
- Controller: `MsdsPhysicalChemicalController` 存在且功能完整
- Service: `IMsdsPhysicalChemicalService` 正确实现
- Mapper: `MsdsPhysicalChemicalMapper.xml` 字段映射有问题

### 4. 关键发现 🔍
**Mapper XML文件中的字段映射错误**导致数据无法正确导入和查询：

1. **resultMap中的字段映射错误**：
   - `evaporationRate` 映射到 `evaporation_rate`，但数据库中没有这个字段
   - `explosiveLimits` 映射到 `explosive_limits`，但数据库中是 `explosive_limit_lower` 和 `explosive_limit_upper`
   - `autoIgnitionTemperature` 映射到 `auto_ignition_temperature`，但数据库中是 `autoignition_temperature`

2. **insert和update语句中的字段错误**：
   - 仍然引用了不存在的字段

## 根本原因分析

**主要问题**：Mapper XML中的字段映射与数据库表结构不匹配

**影响链条**：
1. 数据导入时，Mapper XML中的字段映射错误导致SQL执行失败
2. 数据查询时，字段映射错误导致无法正确获取数据
3. 前端无法获取到理化特性数据，显示为空

## 解决方案

### 修复步骤

#### 1. 修复resultMap中的字段映射

**文件**: `msdsPC/ruoyi-MsdsPc-react/ruoyi-system/src/main/resources/mapper/system/MsdsPhysicalChemicalMapper.xml`

**修复前**:
```xml
<result property="evaporationRate"    column="evaporation_rate"    />
<result property="explosiveLimits"    column="explosive_limits"    />
<result property="autoIgnitionTemperature"    column="auto_ignition_temperature"    />
```

**修复后**:
```xml
<!-- 删除不存在的字段 -->
<result property="explosiveLimitLower"    column="explosive_limit_lower"    />
<result property="explosiveLimitUpper"    column="explosive_limit_upper"    />
<result property="autoIgnitionTemperature"    column="autoignition_temperature"    />
```

#### 2. 修复查询条件中的字段错误

**修复前**:
```xml
<if test="evaporationRate != null  and evaporationRate != ''"> and evaporation_rate like concat('%', #{evaporationRate}, '%')</if>
<if test="explosiveLimits != null  and explosiveLimits != ''"> and explosive_limits like concat('%', #{explosiveLimits}, '%')</if>
<if test="autoIgnitionTemperature != null  and autoIgnitionTemperature != ''"> and auto_ignition_temperature like concat('%', #{autoIgnitionTemperature}, '%')</if>
```

**修复后**:
```xml
<if test="explosiveLimitLower != null  and explosiveLimitLower != ''"> and explosive_limit_lower like concat('%', #{explosiveLimitLower}, '%')</if>
<if test="explosiveLimitUpper != null  and explosiveLimitUpper != ''"> and explosive_limit_upper like concat('%', #{explosiveLimitUpper}, '%')</if>
<if test="autoIgnitionTemperature != null  and autoIgnitionTemperature != ''"> and autoignition_temperature like concat('%', #{autoIgnitionTemperature}, '%')</if>
```

#### 3. 修复insert语句中的字段错误

**修复前**:
```xml
<if test="evaporationRate != null">evaporation_rate,</if>
<if test="explosiveLimits != null">explosive_limits,</if>
<if test="autoIgnitionTemperature != null">auto_ignition_temperature,</if>
```

**修复后**:
```xml
<if test="explosiveLimitLower != null">explosive_limit_lower,</if>
<if test="explosiveLimitUpper != null">explosive_limit_upper,</if>
<if test="autoIgnitionTemperature != null">autoignition_temperature,</if>
```

#### 4. 修复update语句中的字段错误

**修复前**:
```xml
<if test="evaporationRate != null">evaporation_rate = #{evaporationRate},</if>
<if test="explosiveLimits != null">explosive_limits = #{explosiveLimits},</if>
<if test="autoIgnitionTemperature != null">auto_ignition_temperature = #{autoIgnitionTemperature},</if>
```

**修复后**:
```xml
<if test="explosiveLimitLower != null">explosive_limit_lower = #{explosiveLimitLower},</if>
<if test="explosiveLimitUpper != null">explosive_limit_upper = #{explosiveLimitUpper},</if>
<if test="autoIgnitionTemperature != null">autoignition_temperature = #{autoIgnitionTemperature},</if>
```

#### 5. 重启后端服务应用修改
```bash
docker-compose restart msdsbackend
```

## 经验总结与建议

### 1. Mapper XML字段验证
**问题**：Mapper XML中的字段名与数据库表结构不匹配，导致SQL错误。

**建议**：
- 在编写或修改Mapper XML前，先验证数据库表结构
- 使用数据库工具导出表结构，避免字段名错误
- 添加单元测试验证Mapper查询的正确性

### 2. 数据库字段命名规范
**问题**：数据库字段命名不一致（如`auto_ignition_temperature` vs `autoignition_temperature`）。

**建议**：
- 统一数据库字段命名规范
- 使用代码生成工具自动生成Mapper XML
- 定期审查数据库表结构与代码的一致性

### 3. 数据导入验证
**问题**：数据导入失败时没有明确的错误提示。

**建议**：
- 在数据导入过程中添加详细的错误日志
- 验证每个字段的映射关系
- 提供数据导入的验证和回滚机制

### 4. 代码生成工具使用
**问题**：手动编写Mapper XML容易出错。

**建议**：
- 使用MyBatis Generator或类似工具自动生成Mapper XML
- 基于数据库表结构自动生成字段映射
- 定期更新生成的代码以保持一致性
