## 1. 📝 执行摘要 (Executive Summary)

本项目旨在开发一个全面的MSDS（化学品安全技术说明书）管理平台，以实现对危险化学品信息的集中、高效、安全管理。项目基于成熟的RuoYi-React前后端分离框架，技术栈核心为 **Spring Boot**, **React**, **MyBatis**, 和 **MySQL**。

**当前状态**: 项目已完成基础架构搭建和核心功能模块的开发，目前处于 **日志监控系统完善和前端核心编辑功能开发** 的关键阶段。后端三层架构已完成95%，包括元数据抽取、规则映射、模板写出器、Word文档解析等核心模块。前端完成了数据展示和模板下载功能，核心的16节分步编辑表单即将启动开发。项目整体按计划推进，风险可控。

**下一步关键目标**: 
1.  **完成日志与监控系统** (1周)
2.  **完成核心功能——16节分步编辑与智能校验表单** (2-3周)

## 5. 🛠️ 技术实施指南 (Technical Implementation Guide)

### **A. 后端开发规范**
- **统一ResultMap**: 在Mapper XML中，为每个实体定义一个标准的`ResultMap`，包含所有字段映射，避免在每个`select`中重复编写。
- **Service层职责**: Service层应处理核心业务逻辑、事务控制和权限校验。避免在Controller中编写业务代码。
- **统一异常处理**: 使用`@ControllerAdvice`和自定义异常类来处理全局异常，返回统一的错误响应格式。

### **B. 前端开发规范**
- **组件化**: 遵循原子设计原则，将UI拆分为可复用的组件。每个步骤表单应是一个独立的父组件。
- **状态管理**: 推荐使用`React Context`或`Zustand`进行简单的全局状态管理（如用户信息）。对于复杂的表单状态，`React Hook Form`是首选。
- **自定义Hooks**: 将可复用的逻辑（如API请求、草稿保存）封装到自定义Hooks中。
- **代码示例: 分步表单骨架**
  ```tsx
  // src/pages/Msds/Edit/index.tsx
  import { Steps, Button, message } from 'antd';
  import { useForm, FormProvider } from 'react-hook-form';
  import { yupResolver } from '@hookform/resolvers/yup';
  import * as yup from 'yup';

  // ... 引入各个步骤的组件和校验Schema

  const MsdsEditForm = () => {
    const [currentStep, setCurrentStep] = useState(0);
    const methods = useForm({
      resolver: yupResolver(steps[currentStep].schema) // 动态加载当前步骤的校验规则
    });

    const handleNext = async () => {
      const isValid = await methods.trigger(); // 触发当前步骤校验
      if (isValid) {
        setCurrentStep(prev => prev + 1);
      }
    };

    // ...

    return (
      <FormProvider {...methods}>
        <Steps current={currentStep} items={steps.map(s => ({ title: s.title }))} />
        <div>{steps[currentStep].content}</div>
        <div className="steps-action">
          {/* 控制按钮 */}
        </div>
      </FormProvider>
    );
  }
  ```
