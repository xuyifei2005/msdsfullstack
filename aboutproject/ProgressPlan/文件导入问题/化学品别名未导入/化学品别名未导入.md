## 标红区域中文别名处理（可直接复制运行）

### 1) 目标
- 将 PDF/Word 中“化学品别名”字段里的中文（含中英文混排）按中文分隔符正确切分，保留中文与括号注释，不把 CAS 误当成别名。

### 2) 拆分与清洗规则（最终版）
1. 统一标点：把全角标点转半角：，；（）【】→ , ; () []；保留中文顿号“、”。
2. 去断行与中文间空格：移除 PDF 断行造成的换行与中文-中文之间的意外空格（示例：“亚硫\n 酸酯”→“亚硫酸酯”）。
3. 统一分隔符：把分号/竖线/斜杠替换为“、”。
4. 逗号切分需保护数字：只在“非数字-逗号-非数字”处切分，即使用正则 (?<!\d),(?!\d)。
5. 归一空白与重复分隔：把连续[、\s]+ 收敛为单个“、”。
6. 拆分后去噪：去掉首尾标点与空白；过滤空字符串；按出现顺序去重。
7. CAS 检测：完全匹配 ^\d{2,7}-\d{2}-\d$ 的项识别为 CAS，写入 cas_code，不合并进 product_alias。

### 3) Python 脚本片段（复制即可运行）
```python
# -*- coding: utf-8 -*-
import re
from collections import OrderedDict

CAS_RE = re.compile(r"^\d{2,7}-\d{2}-\d$")
FW2HW = str.maketrans({
    '，': ',', '；': ';', '（': '(', '）': ')', '【': '[', '】': ']', '　': ' '
})

# 在中文-中文之间出现的 PDF 断行或空格，视为同一词内部空白，予以移除
CHS_JOINER = re.compile(r"(?<=[\u4e00-\u9fa5])\s+(?=[\u4e00-\u9fa5])")

def split_alias(text: str):
    if not text:
        return []
    s = text.strip().translate(FW2HW)
    # 先把换行替换为单个空格，再移除中文-中文之间的空白
    s = re.sub(r"[\r\n]+", " ", s)
    s = CHS_JOINER.sub("", s)
    # 统一为中文顿号分隔
    s = re.sub(r"[;|/]", '、', s)
    # 非数字两侧的英文逗号才视为分隔符
    s = re.sub(r"(?<!\d),(?!\d)", '、', s)
    # 合并多余分隔与空白
    s = re.sub(r"[、\s]+", '、', s)
    tokens = [t.strip(" 、;，,.:;[]()") for t in s.split('、')]
    tokens = [t for t in tokens if t]
    # 去重保序，过滤纯 CAS
    seen = OrderedDict()
    for t in tokens:
        if not CAS_RE.fullmatch(t):
            seen.setdefault(t, None)
    return list(seen.keys())

if __name__ == '__main__':
    original = """
    在此粘贴：PDF中‘化学品别名’标红区域的原文文本
    """.strip()
    print('\n'.join(split_alias(original)))
```
