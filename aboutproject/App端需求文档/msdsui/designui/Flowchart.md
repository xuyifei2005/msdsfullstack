# MSDS管理系统 - 用户操作流程图

## 1. 流程图概述

本文档描述了MSDS管理系统中用户的主要操作流程，包括微信小程序端的用户流程和Web管理后台的管理员流程。

## 2. 微信小程序端用户流程

### 2.1 用户注册/登录流程

```mermaid
flowchart TD
    A[打开小程序] --> B{是否已登录?}
    B -->|是| C[进入首页]
    B -->|否| D[微信授权登录]
    D --> E{授权成功?}
    E -->|是| F[获取用户信息]
    E -->|否| G[提示授权失败]
    F --> H[创建/更新用户档案]
    H --> C
    G --> D
```

### 2.2 MSDS查阅主流程

```mermaid
flowchart TD
    A[小程序首页] --> B{选择查阅方式}
    B -->|扫码查阅| C[打开扫码页面]
    B -->|搜索查阅| D[打开搜索页面]
    B -->|收藏查阅| E[查看收藏列表]
    
    C --> F[扫描二维码]
    F --> G{扫码成功?}
    G -->|是| H[获取MSDS信息]
    G -->|否| I[提示扫码失败]
    I --> F
    
    D --> J[输入关键词]
    J --> K[显示搜索结果]
    K --> L[选择目标MSDS]
    
    E --> M[显示收藏的MSDS]
    M --> N[选择查看MSDS]
    
    H --> O[显示MSDS详情]
    L --> O
    N --> O
    
    O --> P{用户操作}
    P -->|收藏| Q[添加到收藏]
    P -->|分享| R[打开分享页面]
    P -->|下载| S[下载PDF文件]
    P -->|返回| T[返回上一页]
    
    Q --> U[更新收藏状态]
    R --> V[选择分享方式]
    S --> W[保存到本地]
```

### 2.3 扫码查阅详细流程

```mermaid
flowchart TD
    A[点击扫码按钮] --> B[请求相机权限]
    B --> C{权限获取成功?}
    C -->|否| D[显示权限说明]
    D --> E[引导用户开启权限]
    E --> B
    
    C -->|是| F[打开相机界面]
    F --> G[显示扫码框]
    G --> H{检测到二维码?}
    H -->|否| I[继续扫描]
    I --> H
    
    H -->|是| J[解析二维码内容]
    J --> K{二维码有效?}
    K -->|否| L[提示无效二维码]
    L --> I
    
    K -->|是| M[发送请求获取MSDS]
    M --> N{服务器响应?}
    N -->|失败| O[显示网络错误]
    O --> P[提供重试选项]
    P --> M
    
    N -->|成功| Q{MSDS存在?}
    Q -->|否| R[提示MSDS不存在]
    R --> I
    
    Q -->|是| S[跳转到MSDS详情页]
    S --> T[记录查看历史]
    T --> U[显示MSDS内容]
```

### 2.4 搜索查阅详细流程

```mermaid
flowchart TD
    A[进入搜索页面] --> B[显示搜索框]
    B --> C[用户输入关键词]
    C --> D{输入长度 >= 2?}
    D -->|否| E[等待更多输入]
    E --> C
    
    D -->|是| F[发送搜索请求]
    F --> G{服务器响应?}
    G -->|失败| H[显示搜索失败]
    H --> I[提供重试选项]
    I --> F
    
    G -->|成功| J{有搜索结果?}
    J -->|否| K[显示无结果提示]
    K --> L[建议搜索词]
    L --> C
    
    J -->|是| M[显示搜索结果列表]
    M --> N[用户选择MSDS]
    N --> O[跳转到MSDS详情]
    O --> P[记录查看历史]
    P --> Q[显示MSDS内容]
    
    M --> R{需要更多结果?}
    R -->|是| S[加载更多]
    S --> T[追加显示结果]
    T --> M
```

### 2.5 分享功能流程

```mermaid
flowchart TD
    A[点击分享按钮] --> B[打开分享页面]
    B --> C[显示分享选项]
    C --> D{选择分享方式}
    
    D -->|微信好友| E[调用微信分享API]
    D -->|微信群| F[调用微信群分享API]
    D -->|朋友圈| G[调用朋友圈分享API]
    D -->|复制链接| H[复制分享链接]
    D -->|生成二维码| I[生成分享二维码]
    
    E --> J{分享成功?}
    F --> J
    G --> J
    J -->|是| K[记录分享行为]
    J -->|否| L[显示分享失败]
    
    H --> M[显示复制成功提示]
    I --> N[显示二维码]
    N --> O[提供保存选项]
    
    K --> P[更新分享统计]
    M --> P
    O --> P
    L --> Q[提供重试选项]
```

## 3. Web管理后台流程

### 3.1 管理员登录流程

```mermaid
flowchart TD
    A[访问管理后台] --> B[显示登录页面]
    B --> C[输入用户名/邮箱]
    C --> D[输入密码]
    D --> E[点击登录按钮]
    E --> F[验证用户信息]
    F --> G{验证成功?}
    G -->|否| H[显示错误信息]
    H --> I{重试次数 < 3?}
    I -->|是| C
    I -->|否| J[账户临时锁定]
    
    G -->|是| K[生成访问令牌]
    K --> L[跳转到仪表板]
    L --> M[加载用户权限]
    M --> N[显示对应功能菜单]
```

### 3.2 MSDS数据管理流程

```mermaid
flowchart TD
    A[进入MSDS管理页面] --> B[加载MSDS列表]
    B --> C{选择操作}
    
    C -->|上传新文件| D[打开上传对话框]
    C -->|编辑现有| E[选择MSDS记录]
    C -->|删除文件| F[选择要删除的记录]
    C -->|批量操作| G[选择多个记录]
    
    D --> H[选择PDF文件]
    H --> I[填写基本信息]
    I --> J[提交上传]
    J --> K{上传成功?}
    K -->|否| L[显示错误信息]
    K -->|是| M[解析PDF内容]
    M --> N[自动提取元数据]
    N --> O[保存到数据库]
    O --> P[生成二维码]
    P --> Q[更新列表显示]
    
    E --> R[打开编辑表单]
    R --> S[修改MSDS信息]
    S --> T[保存更改]
    T --> U{保存成功?}
    U -->|是| V[更新版本号]
    U -->|否| W[显示保存失败]
    V --> Q
    
    F --> X[确认删除操作]
    X --> Y{确认删除?}
    Y -->|否| C
    Y -->|是| Z[执行删除]
    Z --> AA[更新相关二维码状态]
    AA --> Q
```

### 3.3 用户权限管理流程

```mermaid
flowchart TD
    A[进入用户管理页面] --> B[加载用户列表]
    B --> C{选择操作}
    
    C -->|添加用户| D[打开新增用户表单]
    C -->|编辑用户| E[选择用户记录]
    C -->|删除用户| F[选择要删除的用户]
    C -->|重置密码| G[选择用户]
    
    D --> H[填写用户信息]
    H --> I[设置角色权限]
    I --> J[提交创建]
    J --> K{创建成功?}
    K -->|是| L[发送邀请邮件]
    K -->|否| M[显示创建失败]
    L --> N[更新用户列表]
    
    E --> O[打开编辑表单]
    O --> P[修改用户信息]
    P --> Q[更新权限设置]
    Q --> R[保存更改]
    R --> S{保存成功?}
    S -->|是| N
    S -->|否| T[显示保存失败]
    
    F --> U[确认删除操作]
    U --> V{确认删除?}
    V -->|否| C
    V -->|是| W[检查用户关联数据]
    W --> X[执行删除或禁用]
    X --> N
    
    G --> Y[生成临时密码]
    Y --> Z[发送重置邮件]
    Z --> N
```

### 3.4 二维码管理流程

```mermaid
flowchart TD
    A[进入二维码管理页面] --> B[加载二维码列表]
    B --> C{选择操作}
    
    C -->|生成新二维码| D[选择MSDS文件]
    C -->|批量生成| E[选择多个MSDS]
    C -->|编辑二维码| F[选择二维码记录]
    C -->|下载二维码| G[选择要下载的二维码]
    
    D --> H[设置二维码参数]
    H --> I[选择尺寸和格式]
    I --> J[生成二维码]
    J --> K{生成成功?}
    K -->|是| L[保存二维码信息]
    K -->|否| M[显示生成失败]
    L --> N[更新列表显示]
    
    E --> O[设置批量参数]
    O --> P[确认批量生成]
    P --> Q[逐个生成二维码]
    Q --> R[显示生成进度]
    R --> S{全部完成?}
    S -->|否| Q
    S -->|是| T[显示批量结果]
    T --> N
    
    F --> U[打开编辑表单]
    U --> V[修改二维码信息]
    V --> W[重新生成二维码]
    W --> X[保存更改]
    X --> N
    
    G --> Y[选择下载格式]
    Y --> Z[打包下载文件]
    Z --> AA[提供下载链接]
```

## 4. 异常处理流程

### 4.1 网络异常处理

```mermaid
flowchart TD
    A[发起网络请求] --> B{网络连接正常?}
    B -->|否| C[显示网络错误提示]
    C --> D[提供重试按钮]
    D --> E{用户选择重试?}
    E -->|是| A
    E -->|否| F[返回上一页面]
    
    B -->|是| G[发送请求]
    G --> H{服务器响应?}
    H -->|超时| I[显示请求超时]
    H -->|错误| J[显示服务器错误]
    H -->|成功| K[处理响应数据]
    
    I --> D
    J --> D
```

### 4.2 权限异常处理

```mermaid
flowchart TD
    A[用户操作请求] --> B[检查用户权限]
    B --> C{权限验证通过?}
    C -->|否| D[显示权限不足提示]
    D --> E[引导联系管理员]
    E --> F[返回安全页面]
    
    C -->|是| G[检查会话状态]
    G --> H{会话有效?}
    H -->|否| I[显示会话过期]
    I --> J[引导重新登录]
    J --> K[跳转到登录页]
    
    H -->|是| L[执行用户操作]
```

### 4.3 数据异常处理

```mermaid
flowchart TD
    A[数据操作请求] --> B[验证数据格式]
    B --> C{数据格式正确?}
    C -->|否| D[显示格式错误提示]
    D --> E[高亮错误字段]
    E --> F[等待用户修正]
    
    C -->|是| G[检查数据完整性]
    G --> H{数据完整?}
    H -->|否| I[显示缺失字段提示]
    I --> E
    
    H -->|是| J[执行数据操作]
    J --> K{操作成功?}
    K -->|否| L[显示操作失败]
    L --> M[提供错误详情]
    M --> N[提供重试选项]
    
    K -->|是| O[显示操作成功]
    O --> P[更新界面状态]
```

## 5. 性能优化流程

### 5.1 数据加载优化

```mermaid
flowchart TD
    A[页面加载开始] --> B[显示加载骨架屏]
    B --> C[并行加载关键数据]
    C --> D[优先渲染首屏内容]
    D --> E[延迟加载非关键内容]
    E --> F[实现虚拟滚动]
    F --> G[缓存常用数据]
    G --> H[页面加载完成]
```

### 5.2 图片加载优化

```mermaid
flowchart TD
    A[图片加载请求] --> B[检查本地缓存]
    B --> C{缓存存在?}
    C -->|是| D[使用缓存图片]
    C -->|否| E[显示占位图]
    E --> F[懒加载图片]
    F --> G[压缩图片质量]
    G --> H[保存到缓存]
    H --> I[显示实际图片]

```
