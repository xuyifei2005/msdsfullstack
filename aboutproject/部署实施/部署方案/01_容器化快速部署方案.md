## 📦 部署步骤

### 第一步：环境准备

#### 1.1 安装Docker

```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# CentOS/RHEL
sudo yum install -y docker
sudo systemctl start docker
sudo systemctl enable docker
```

#### 1.2 安装Docker Compose

```bash
# 下载Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

# 添加执行权限
sudo chmod +x /usr/local/bin/docker-compose

# 验证安装
docker-compose --version
```

#### 1.3 克隆项目代码

```bash
# 克隆项目
git clone https://github.com/your-org/msdsfullstack.git
cd msdsfullstack

# 进入部署目录
cd msdsdocker
```

### 第二步：配置环境

#### 2.1 配置环境变量

```bash
# 复制环境配置文件
cp .env.prod.example .env.prod

# 编辑配置文件
vim .env.prod
```

**环境变量配置**:
```bash
# 数据库配置
MYSQL_ROOT_PASSWORD=your_secure_password
MYSQL_DATABASE=msds_dev
MYSQL_USER=msds_user
MYSQL_PASSWORD=msds_dev_password

# Redis配置
REDIS_PASSWORD=your_redis_password

# 应用配置
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-domain.com

# SSL证书配置
SSL_CERT_PATH=/etc/nginx/ssl/cert.pem
SSL_KEY_PATH=/etc/nginx/ssl/key.pem
```

#### 2.2 配置SSL证书（可选）

```bash
# 创建SSL目录
mkdir -p nginx/ssl

# 复制SSL证书
cp your-cert.pem nginx/ssl/cert.pem
cp your-key.pem nginx/ssl/key.pem

# 设置权限
chmod 600 nginx/ssl/*
```

### 第三步：一键部署

#### 3.1 使用自动化脚本

```bash
# 给脚本执行权限
chmod +x deploy.sh

# 执行部署
./deploy.sh
```

#### 3.2 手动部署（可选）

```bash
# 构建并启动服务
docker-compose -f docker-compose.yml up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f
```

### 第四步：验证部署

#### 4.1 健康检查

```bash
# 检查所有容器状态
docker-compose ps

# 检查服务健康状态
curl http://localhost:180/health
curl http://localhost:8080/actuator/health

# 检查数据库连接
docker-compose exec msdsmysql mysql -u msds_user -p -e "SELECT 1"
```

#### 4.2 功能验证

```bash
# 访问前端页面
curl -I http://localhost:180

# 访问后端API
curl http://localhost:8080/api/system/user/profile

# 检查数据库数据
docker-compose exec msdsmysql mysql -u msds_user -p msds_dev -e "SHOW TABLES"
```

## 🔧 运维管理

### 日常操作

#### 启动服务

```bash
cd /opt/msds/msdsdocker
docker-compose up -d
```

#### 停止服务

```bash
docker-compose down
```

#### 重启服务

```bash
docker-compose restart
```

#### 查看日志

```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f msdsbackend
docker-compose logs -f msdsfrontend
docker-compose logs -f msdsmysql
```

### 数据备份

#### 自动备份

```bash
# 使用备份脚本
./backup-restore.sh backup

# 定时备份（添加到crontab）
0 2 * * * /opt/msds/msdsdocker/backup-restore.sh backup
```

#### 手动备份

```bash
# 备份数据库
docker-compose exec msdsmysql mysqldump -u msds_user -p msds_dev > backup_$(date +%Y%m%d_%H%M%S).sql

# 备份文件数据
tar -czf files_backup_$(date +%Y%m%d_%H%M%S).tar.gz ./data/files
```

### 数据恢复

```bash
# 恢复数据库
docker-compose exec -T msdsmysql mysql -u msds_user -p msds_dev < backup_20240127_020000.sql

# 恢复文件数据
tar -xzf files_backup_20240127_020000.tar.gz -C ./data/
```

### 更新部署

#### 更新应用代码

```bash
# 拉取最新代码
git pull origin main

# 重新构建并部署
docker-compose down
docker-compose build --no-cache
docker-compose up -d
```

#### 更新单个服务

```bash
# 更新后端服务
docker-compose build msdsbackend
docker-compose up -d msdsbackend

# 更新前端服务
docker-compose build msdsfrontend
docker-compose up -d msdsfrontend
```

## 🚨 故障排查

### 常见问题

#### 问题1：容器启动失败

**症状**: 容器无法启动或频繁重启

**排查步骤**:
```bash
# 查看容器状态
docker-compose ps

# 查看容器日志
docker-compose logs [service_name]

# 检查端口占用
netstat -tlnp | grep [port]

# 检查磁盘空间
df -h
```

**解决方案**:
- 检查端口是否被占用
- 确认磁盘空间充足
- 检查配置文件语法
- 重新构建镜像

#### 问题2：数据库连接失败

**症状**: 应用无法连接数据库

**排查步骤**:
```bash
# 检查数据库容器状态
docker-compose ps msdsmysql

# 测试数据库连接
docker-compose exec msdsmysql mysql -u msds_user -p

# 检查网络连接
docker-compose exec msdsbackend ping msdsmysql
```

**解决方案**:
- 确认数据库容器正常运行
- 检查数据库用户权限
- 验证网络连接
- 重启数据库服务

#### 问题3：前端页面无法访问

**症状**: 浏览器无法打开前端页面

**排查步骤**:
```bash
# 检查Nginx状态
docker-compose ps msdsnginx

# 检查Nginx配置
docker-compose exec msdsnginx nginx -t

# 查看Nginx日志
docker-compose logs msdsnginx
```

**解决方案**:
- 检查Nginx配置文件
- 确认端口映射正确
- 重启Nginx服务
- 检查防火墙设置

### 紧急恢复

## 🔒 安全配置

### 基础安全

#### 防火墙配置

```bash
# Ubuntu/Debian
sudo ufw allow 22/tcp
sudo ufw allow 180/tcp
sudo ufw allow 11443/tcp
sudo ufw enable

# CentOS/RHEL
sudo firewall-cmd --permanent --add-port=22/tcp
sudo firewall-cmd --permanent --add-port=180/tcp
sudo firewall-cmd --permanent --add-port=11443/tcp
sudo firewall-cmd --reload
```

#### SSL/TLS配置

```bash
# 生成自签名证书（测试用）
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout nginx/ssl/key.pem \
  -out nginx/ssl/cert.pem

# 或使用Let's Encrypt
certbot certonly --standalone -d your-domain.com
```

### 数据安全

#### 数据库安全

```bash
# 修改默认密码
docker-compose exec msdsmysql mysql -u root -p -e "ALTER USER 'root'@'%' IDENTIFIED BY 'new_secure_password';"

# 删除测试数据库
docker-compose exec msdsmysql mysql -u root -p -e "DROP DATABASE IF EXISTS test;"

# 创建只读用户
docker-compose exec msdsmysql mysql -u root -p -e "CREATE USER 'readonly'@'%' IDENTIFIED BY 'readonly_password';"
docker-compose exec msdsmysql mysql -u root -p -e "GRANT SELECT ON msds_dev.* TO 'readonly'@'%';"
```

#### 文件权限

```bash
# 设置适当的文件权限
chmod 600 .env.prod
chmod 600 nginx/ssl/*
chmod 755 deploy.sh
chmod 755 backup-restore.sh
```

## 📈 性能优化

### 数据库优化

#### MySQL配置优化

```bash
# 编辑MySQL配置
vim mysql/conf.d/mysql.cnf
```

```ini
[mysqld]
# 内存配置
innodb_buffer_pool_size = 2G
innodb_log_file_size = 256M
innodb_log_buffer_size = 16M

# 连接配置
max_connections = 200
max_connect_errors = 10000

# 查询缓存
query_cache_type = 1
query_cache_size = 128M

# 慢查询日志
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2
```

#### Redis配置优化

```bash
# 编辑Redis配置
vim redis/redis.conf
```

```ini
# 内存配置
maxmemory 1gb
maxmemory-policy allkeys-lru

# 持久化配置
save 900 1
save 300 10
save 60 10000

# 网络配置
tcp-keepalive 300
timeout 0
```

### 应用优化

#### JVM参数优化

```bash
# 在docker-compose.yml中配置
environment:
  - JAVA_OPTS=-Xms2g -Xmx4g -XX:+UseG1GC -XX:MaxGCPauseMillis=200
```

#### Nginx优化

```nginx
# nginx.conf优化配置
worker_processes auto;
worker_connections 1024;

# 启用gzip压缩
gzip on;
gzip_vary on;
gzip_min_length 1024;
gzip_types text/plain text/css application/json application/javascript;

# 缓存配置
location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}
```
