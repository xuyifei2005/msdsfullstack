## 🎯 三步部署流程

### 第一步：准备服务器环境 (10分钟)

```bash
# 1. SSH连接到服务器
ssh root@39.107.211.72

# 2. 安装Docker和Docker Compose
curl -fsSL https://get.docker.com | bash
curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 3. 验证安装
docker --version
docker-compose --version

# 4. 配置防火墙
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable





# 5. 创建项目目录
mkdir -p /opt/msds /opt/msds-backup
```

### 第三步：配置并启动 (2分钟)

```bash

# 1. 配置环境变量

nano .env.prod

# 修改以下内容（必须！）：
# MYSQL_ROOT_PASSWORD=root
```

## 🔧 常用维护命令

```bash
# 查看所有容器状态
docker ps

# 查看后端日志
docker logs -f msdsbackend-prod

# 查看Nginx日志
docker logs -f msdsnginx-prod

# 重启服务
cd /opt/msds/msdsdocker
docker-compose -f docker-compose.prod.yml restart

# 备份数据库
./backup-restore.sh full

# 停止所有服务
docker-compose -f docker-compose.prod.yml down

# 启动所有服务
docker-compose -f docker-compose.prod.yml up -d
```

## 🛡️ 安全设置（部署后立即执行）

```bash
# 1. 修改应用管理员密码
# 登录系统 → 个人中心 → 修改密码

# 2. 修改数据库root密码
docker exec -it msdsmysql-prod mysql -u root -p
# 执行: ALTER USER 'root'@'%' IDENTIFIED BY 'new_password';

# 3. 设置自动备份
crontab -e
# 添加: 0 2 * * * /opt/msds/msdsdocker/backup-restore.sh auto >> /var/log/msds-backup.log 2>&1

# 4. 禁用root SSH登录
nano /etc/ssh/sshd_config
# 修改: PermitRootLogin no
systemctl restart sshd
```

## 📞 遇到问题？

### 容器无法启动
```bash
# 查看错误日志
docker logs msdsbackend-prod

# 检查配置
cat .env.prod

# 验证配置正确性
docker-compose -f docker-compose.prod.yml config
```

### 无法访问网站
```bash
# 检查Nginx状态
docker ps | grep nginx

# 检查防火墙
ufw status

# 检查端口
netstat -tulpn | grep :443

# 检查域名DNS解析
nslookup flymsds.cn
```

### 数据库连接失败
```bash
# 检查MySQL容器
docker ps | grep mysql

# 测试连接
docker exec -it msdsmysql-prod mysql -u root -p

# 重启MySQL
docker-compose -f docker-compose.prod.yml restart msdsmysql
```
