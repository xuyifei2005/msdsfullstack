## 🚀 下一步操作（必须！）

### 步骤1：配置GitHub Secrets（5分钟）⭐

在GitHub仓库中添加以下Secrets：

```
Settings → Secrets and variables → Actions → New repository secret
```

**必需的Secrets**：
1. **ALIYUN_REGISTRY_USERNAME** - 阿里云镜像仓库用户名
2. **ALIYUN_REGISTRY_PASSWORD** - 阿里云镜像仓库密码  
3. **PRODUCTION_HOST** - `39.107.211.72`
4. **PRODUCTION_USER** - `root` 或专用部署用户
5. **PRODUCTION_SSH_KEY** - SSH私钥（完整内容）

📘 **详细步骤**：[./GitHub_Secrets配置指南.md](./GitHub_Secrets配置指南.md)

---

### 步骤2：生成SSH密钥（如未有）

```bash
# 生成密钥对
ssh-keygen -t rsa -b 4096 -C "deploy@msds" -f ~/.ssh/msds_deploy

# 查看私钥（复制到GitHub Secrets）
cat ~/.ssh/msds_deploy

# 添加公钥到服务器
ssh-copy-id -i ~/.ssh/msds_deploy.pub root@39.107.211.72
```
