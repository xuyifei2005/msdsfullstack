## 🚀 推荐部署方案

### 方案A：Linux服务器部署（强烈推荐）⭐⭐⭐⭐⭐

**为什么推荐Linux？**
- ✅ 稳定性更好
- ✅ Docker支持更完善
- ✅ 脚本兼容性好
- ✅ 资源占用更少
- ✅ 生产环境标准

**快速部署步骤**:

```bash
# 1. 连接服务器
ssh root@39.107.211.72

# 2. 安装Docker（首次需要）
curl -fsSL https://get.docker.com | bash

# 3. 上传项目到 /opt/msds
# （从Windows本地使用SCP/SFTP上传）

# 4. 配置环境变量
cd /opt/msds/msdsdocker
cp env.prod.example .env.prod
nano .env.prod  # 修改所有密码

# 5. 一键部署
chmod +x deploy.sh backup-restore.sh
./deploy.sh
```

**预计时间**: 15-20分钟（包含首次安装Docker）
