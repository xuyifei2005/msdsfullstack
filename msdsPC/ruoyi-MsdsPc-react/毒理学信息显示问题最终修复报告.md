# 毒理学信息显示问题最终修复报告

## 问题总结

经过深入排查，发现了毒理学信息无法显示的根本原因：**MyBatis映射文件中的字段不匹配问题**。

## 问题根因分析

### 1. 数据库表结构问题 ✅ 已修复
**问题**: `msds_toxicological`表没有`create_time`、`update_time`、`create_by`、`update_by`字段
**影响**: MyBatis查询语句包含不存在的字段，导致SQL查询失败

**数据库实际字段**:
```sql
-- msds_toxicological表实际字段
id, msds_id, acute_toxicity, ld50_oral, ld50_dermal, lc50_inhalation,
subacute_chronic, skin_irritation, eye_irritation, respiratory_irritation,
sensitization, mutagenicity, teratogenicity, reproductive_toxicity,
carcinogenicity, carcinogen_classification, specific_target_organ,
aspiration_hazard, other_toxicity, rtecs
```

**MyBatis映射文件错误字段**:
```xml
<!-- 错误的查询语句 -->
<sql id="selectMsdsToxicologicalVo">
    select id, msds_id, acute_toxicity, ld50_oral, ld50_dermal, lc50_inhalation,
           subacute_chronic, skin_irritation, eye_irritation, respiratory_irritation,
           sensitization, mutagenicity, teratogenicity, reproductive_toxicity,
           carcinogenicity, carcinogen_classification, specific_target_organ,
           aspiration_hazard, other_toxicity, rtecs, 
           create_time, update_time, create_by, update_by  -- ❌ 这些字段不存在
    from msds_toxicological
</sql>
```

### 2. 前端API路径问题 ✅ 已修复
**问题**: 前端调用`/api/system/toxicology`，后端路径是`/system/toxicological`
**修复**: 统一API路径为`/api/system/toxicological`

### 3. 前端数据加载问题 ✅ 已修复
**问题**: MSDS详情页面没有加载毒理学信息
**修复**: 添加了毒理学信息的并行加载逻辑

### 3. 修复前端数据加载逻辑 ✅

**文件**: `react-ui/src/pages/Msds/components/MsdsDetail.tsx`

```typescript
// 添加毒理学信息API导入
import { getToxicologyByMsdsId } from '@/services/msds/toxicology';

// 修改数据加载函数
const fetchMsdsDetail = async () => {
  setLoading(true);
  try {
    // 并行加载MSDS主信息和毒理学信息
    const [msdsResponse, toxicologyResponse] = await Promise.all([
      getMsdsDetail(msdsId),
      getToxicologyByMsdsId(msdsId)
    ]);
    
    if (msdsResponse.code === 200) {
      const msdsData = msdsResponse.data;
      
      // 如果毒理学信息加载成功，添加到MSDS数据中
      if (toxicologyResponse.code === 200 && toxicologyResponse.data) {
        msdsData.toxicological = toxicologyResponse.data;
      }
      
      setMsdsData(msdsData);
    } else {
      message.error('获取MSDS详情失败');
    }
  } catch (error) {
    console.error('加载MSDS详情失败:', error);
    message.error('获取MSDS详情失败');
  } finally {
    setLoading(false);
  }
};
```
