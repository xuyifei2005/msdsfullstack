# 用户故事地图 (User Story Map) - MSDS 管理文件系统

## 1. 用户故事地图概述

本用户故事地图旨在通过可视化方式，展现“MSDS 管理文件系统”的用户活动、用户任务以及具体的用户故事。它帮助团队从用户视角理解产品功能，梳理用户流程，并为版本规划和迭代提供依据。地图的横向代表用户的主要活动流 (User Activities)，纵向则分解为具体的用户任务 (User Tasks) 和更细粒度的用户故事 (User Stories)。

**核心用户角色**: 
-   **科研人员 (Researcher)**: 主要使用系统查阅MSDS，获取安全信息。
-   **实验室管理员 (LabAdmin)**: 主要负责MSDS的上传、管理、维护和用户权限分配。

## 2. 用户活动流 (横向骨干 Backbone)

| 用户活动 (User Activities) | 目标用户        |
|----------------------------|-----------------|
| **1. 系统准备与访问**      | Researcher, LabAdmin |
| **2. MSDS 信息获取与查阅** | Researcher      |
| **3. MSDS 文档管理**       | LabAdmin        |
| **4. 用户与权限管理**      | LabAdmin        |
| **5. 系统维护与配置**      | LabAdmin        |
| **6. 安全与合规扩展**      | LabAdmin, Researcher |

- **核心主题**: 实现MSDS的“存、搜、看”核心闭环。
- **包含的用户故事 (P0为主)**:
    - (1.1) 首次安装与配置 (PC端)

    - (2.3) 预览MSDS内容 (PDF, 基本操作)
    - (2.4) 下载MSDS文件
    - (3.1) 上传单个MSDS
    - (3.3) 编辑MSDS元数据 (基础字段)
    - (4.1) 创建与管理用户账户 (基础)

### Release 2: V1.1 (MVP 优化)
- **核心主题**: 提升搜索与预览体验，补充基础管理功能。
- **包含的用户故事 (P1为主)**:
    - (2.1) 搜索MSDS (模糊搜索)

    - (2.2) 查看搜索结果 (排序)
    - (2.3) 预览MSDS内容 (内部文本搜索)
    - (3.3) 编辑MSDS元数据 (自定义分类/标签 - 基础)
    - (3.7) 查看MSDS操作日志 (基础)

### Release 3: V2.0 (功能完善)
- **核心主题**: 完善管理流程，增强协作与合规性，提升系统健壮性。
- **包含的用户故事 (P0, P1为主)**:

    - (3.5) 删除/归档MSDS

    - (3.7) 查看MSDS操作日志 (完善)
    - (4.2) 管理用户角色 (完善)
    - (4.3) 分配用户权限 (完善)
    - (5.1) 查看系统状态与日志
    - (5.2) 数据备份与恢复
    - ... (及其他V2.0规划的故事)
