## 技术架构关键确认

### 小程序端实际技术栈

1. **开发技术栈**
   - **基础框架**: RuoYi-App移动端框架
   - **多端框架**: UniApp（Vue.js生态）
   - **UI组件**: uView UI + ColorUI
   - **开发工具**: HBuilderX
   - **调试工具**: 微信开发者工具
   - **RuoYi集成**: 登录认证、权限验证、字典管理

2. **开发环境**
   - **宿主系统**: Windows 11
   - **运行位置**: 不在Docker容器中，直接在Windows主机运行
   - **编译流程**: HBuilderX → 微信开发者工具

3. **后端连接**
   - **开发环境**: 通过WSL2局域网IP连接（如：http://192.168.x.x:8080）
   - **生产环境**: 通过域名连接（如：https://api.flymsds.cn）

### 后端服务架构

1. **后端技术栈**
   - Java Spring Boot + RuoYi框架
   - MyBatis Plus数据访问层
   - MySQL 8.0数据库

2. **运行环境**
   - **容器化**: Docker Compose
   - **宿主环境**: Windows 11 + WSL2 + Docker Desktop
   - **必须在Docker容器内编译和运行**

### 开发流程明确

1. **小程序开发**:
   - 代码编辑：HBuilderX
   - 编译：HBuilderX自动编译
   - 运行调试：微信开发者工具
   - 真机预览：扫码预览

2. **后端开发**:
   - 代码编辑：Windows主机IDE
   - 代码编译：Docker容器内（docker-compose exec backend bash）
   - 服务运行：Docker容器内

3. **网络配置**:
   - 小程序→后端：WSL2局域网IP（开发）/ 域名（生产）
   - 后端容器间：容器名称（mysql:3306）
   - 主机→容器：localhost映射端口
