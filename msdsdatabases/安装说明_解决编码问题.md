# MSDS数据库安装说明 - 编码问题解决方案

## 问题描述

在Windows环境下执行MySQL脚本时遇到两个主要问题：

1. **PowerShell重定向语法问题**: `mysql -u root -p < script.sql` 语法在PowerShell中不被支持
2. **文件编码问题**: 中文文件名在MySQL中出现乱码 `'鏁版嵁搴撴枃妗ｇ粨鏋勫瓨鍌ㄨ〃.sql'`

## 解决方案

### 方案一：使用批处理文件（推荐）

```bash
# 直接运行批处理文件
.\install_msds.bat
```

**优点**：
- 完全兼容MySQL重定向语法
- 自动处理编码问题
- 用户友好的界面

### 方案二：使用PowerShell脚本

```powershell
# 运行PowerShell脚本
.\install_msds.ps1
```

**优点**：
- 使用Get-Content管道避免重定向问题
- 彩色输出界面
- 更好的错误处理

### 方案三：手动执行（备用方案）

如果上述方案都不工作，可以手动执行：

```powershell
# 方法1: 在MySQL命令行中执行
mysql -u root -p
# 然后在MySQL提示符下：
source D:/msdsfullstack/msdsdatabases/install_msds_database.sql

# 方法2: 使用MySQL Workbench
# 打开MySQL Workbench，直接打开并执行 install_msds_database.sql 文件
```

## 编码问题根因分析

### 问题1: PowerShell重定向
```powershell
# ❌ 错误写法 - PowerShell不支持
mysql -u root -p < script.sql

# ✅ 正确写法 - 使用管道
Get-Content script.sql | mysql -u root -p
```

### 问题2: 中文文件名编码
```sql
-- ❌ 错误 - 使用SOURCE命令引用中文文件名
SOURCE 数据库文档结构存储表.sql

-- ✅ 正确 - 将所有SQL合并到一个文件中
-- 直接包含SQL语句，避免文件引用
```

### 问题3: MySQL字符集设置
```sql
-- 确保使用正确的字符集
CREATE DATABASE msds_management 
DEFAULT CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

## 安装验证

安装成功后，可以执行以下验证：

```sql
-- 连接数据库
mysql -u root -p

-- 使用数据库
USE msds_management;

-- 检查表数量
SELECT COUNT(*) as table_count 
FROM information_schema.tables 
WHERE table_schema = 'msds_management';

-- 检查基础数据
SELECT COUNT(*) as category_count FROM chemical_category;
SELECT COUNT(*) as ghs_class_count FROM ghs_hazard_class;

-- 显示所有表
SHOW TABLES;
```

## 故障排除

### 常见错误及解决方案

1. **权限不足**
   ```
   解决方案: 以管理员身份运行命令提示符或PowerShell
   ```

2. **MySQL服务未启动**
   ```
   解决方案: 启动MySQL服务
   net start mysql
   ```

3. **路径问题**
   ```
   解决方案: 确保在msdsdatabases目录下执行安装脚本
   cd D:\msdsfullstack\msdsdatabases
   ```

4. **编码问题持续存在**
   ```
   解决方案: 使用MySQL Workbench GUI工具执行脚本
   ```

## 注意事项

1. **备份重要数据**: 安装前请备份现有MySQL数据
2. **权限要求**: 需要MySQL root权限或具有CREATE DATABASE权限的用户
3. **字符集**: 确保客户端和服务器都支持UTF-8编码
4. **版本兼容**: 建议使用MySQL 5.7+或8.0+版本
