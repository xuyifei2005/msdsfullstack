## 文档信息

- **版本**: v2.0
- **更新日期**: 2025-01-27
- **适用范围**: MSDS实验室管理系统全栈开发项目
- **维护者**: AI PM

## 0. 核心开发原则

### 0.1 开发环境原则

- **本地主机开发**: 在本地主机上进行代码开发、修改和编写
- **容器内运行**: 仅在Docker容器内编译和运行系统
- **编译确认**: 如需自动编译，必须先提示用户确认
- **工具优先**: 优先使用MCP工具进行问题处理
- **源码直接修改**: 直接在源码中修改，避免创建过多无用的测试脚本文件和文档

### 0.2 AI助手协作规范

- **MCP工具优先**: 优先使用MCP（Model Context Protocol）工具处理问题
- **直接源码修改**: 避免创建临时测试文件，直接修改源码
- **最小化文件创建**: 不创建不必要的测试脚本和文档文件
- **确认机制**: 重要操作（如编译、部署）需要用户确认
- **工具链使用**: 充分利用现有的开发工具链和自动化脚本

### 1.2 技术栈说明

**重要：本项目技术栈配置**

#### 1.2.1 核心技术栈

- **数据库**: MySQL 8.0.42 (容器名: msdsmysql)
- **缓存**: Redis (容器名: msdsredis)
- **后端**: Spring Boot + Java (容器名: msdsbackend)
- **前端**: React (容器名: msdsfrontend)
- **反向代理**: Nginx (容器名: msdsnginx)
- **移动端**: UniApp (微信小程序)
- **基础框架**: RuoYi (前后端分离版本)

#### 1.2.2 重要说明

- **不使用PostgreSQL**: 本项目专门使用MySQL数据库
- **不使用Nacos**: 本项目不使用Nacos注册中心
- **容器化部署**: 所有服务均通过Docker容器部署

#### 1.2.3 容器端口映射

- **MySQL**: 3306:3306
- **Redis**: 1379:6379
- **后端**: 18080:8080, 5005:5005 (调试端口), 2222:22 (SSH)
- **前端**: 3000:3000, 8000:8000, 2223:22 (SSH)
- **Nginx**: 180:80, 1443:443

### 1.3 命名规范

- **文件夹名称**: 使用小写字母，多个单词用下划线连接
- **代码文件**: 使用驼峰命名法

- **SQL文件**: 使用下划线命名法
- **配置文件**: 使用小写字母和点分隔符

## 3. 开发规范

### 3.1 MSDS项目特定配置

#### 3.1.1 数据库连接配置

- **数据库URL**: `jdbc:mysql://msdsmysql:3306/msds_dev?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true`
- **用户名**: `msds_user`
- **密码**: `msds_dev_password`
- **数据库名**: `msds_dev`
- **字符集**: UTF-8
- **时区**: UTC

#### 3.1.2 MSDS文档导入功能

- **文件名格式**: `中文名、英文名、CAS号.txt` 或 `中文名,英文名,CAS号.txt`
- **数据映射**: 
  - 中文名 → product_name
  - 英文名 → product_english_name
  - CAS号 → product_alias
- **支持格式**: PDF、TXT、XML
- **批量处理**: 支持批量导入和转换

#### 3.1.3 PDF转换工具规范

- **转换工具**: 使用pdf2xml目录下的工具

- **错误处理**: 完善的错误处理和日志记录
