# MSDS实验室管理系统快速部署指南

## 🚀 一键部署

### 前置要求
- Docker 20.10+
- Docker Compose 2.0+
- 8GB+ 内存
- 20GB+ 磁盘空间

### 快速启动

```bash
# 1. 进入部署目录
cd msdsdocker

# 2. 启动MSDS主系统
docker-compose up -d

# 3. 启动监控系统
docker-compose -f docker-compose.monitoring-simple.yml up -d

# 4. 验证部署
docker ps --filter "name=msds"
```

### 访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 🌐 MSDS前端 | http://localhost:8000 | 主应用界面 |
| 🔧 MSDS后端 | http://localhost:18080 | API服务 |
| 📊 Grafana监控 | http://localhost:13000 | 监控面板 (admin/admin) |
| 📈 Prometheus | http://localhost:9090 | 指标收集 |
| 🔍 cAdvisor | http://localhost:18081 | 容器监控 |

### 健康检查

```bash
# 检查所有服务状态
docker ps --filter "name=msds" --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

# 测试API响应
curl http://localhost:18080/captchaImage

# 测试前端访问
curl http://localhost:8000
```

### 常用命令

```bash
# 查看日志
docker-compose logs -f

# 重启服务
docker-compose restart

# 停止服务
docker-compose down

# 清理系统
docker system prune -f
```

## 🔧 故障排除

### 端口冲突
如果遇到端口占用，修改docker-compose.yml中的端口映射：
```yaml
ports:
  - "新端口:容器端口"
```

### 容器启动失败
```bash
# 查看详细错误
docker-compose logs 容器名

# 重新构建镜像
docker-compose build --no-cache
```

### 数据库连接问题
```bash
# 检查数据库状态
docker exec -it msdsmysql mysql -u msds_user -pmsds_dev_password -e "SELECT 1"
```
