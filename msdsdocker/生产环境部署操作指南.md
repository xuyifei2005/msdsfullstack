# MSDS系统生产环境部署操作指南 🚀

## 📋 部署概览

本指南将帮助您将MSDS实验室管理系统部署到生产服务器。整个部署过程分为三种方式：

1. **🎯 一键自动部署**（推荐）- 使用自动化脚本
2. **📝 手动分步部署** - 逐步执行命令
3. **🔧 高级自定义部署** - 自定义配置

---

## 🎯 方式一：一键自动部署（推荐）

### 前提条件
- ✅ 本地已完成前后端打包
- ✅ 服务器已安装Docker和Docker Compose
- ✅ 已配置SSH密钥认证（可选，避免重复输入密码）

### 执行步骤

#### 选项A：使用PowerShell脚本（推荐）
```powershell
# 1. 打开PowerShell（以管理员身份运行）
cd D:\XUYIFEI\XUPROJECTS\msdsfullstack\msdsdocker

# 2. 设置执行策略（如果需要）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 3. 执行一键部署
.\deploy-production.ps1

# 4. 可选参数：
# 跳过前端构建（如果已构建）
.\deploy-production.ps1 -SkipBuild

# 跳过文件上传（如果已上传）
.\deploy-production.ps1 -SkipUpload

# 强制部署（跳过确认）
.\deploy-production.ps1 -Force

# 自定义服务器信息
.\deploy-production.ps1 -ServerIP "39.107.211.72" -ServerUser "root" -Domain "flymsds.cn"
```

#### 选项B：使用批处理脚本
```cmd
# 1. 打开命令提示符
cd D:\XUYIFEI\XUPROJECTS\msdsfullstack\msdsdocker

# 2. 执行一键部署
一键部署脚本.bat
```

### 部署过程说明
脚本将自动执行以下步骤：
1. ✅ 检查本地环境和必要文件
2. ✅ 构建前端应用（如果需要）
3. ✅ 测试服务器连接
4. ✅ 创建服务器目录结构
5. ✅ 上传项目文件和配置
6. ✅ 检查SSL证书
7. ✅ 执行生产环境部署

## 📝 方式二：手动分步部署

### 步骤1：准备本地环境

```powershell
# 1. 确保前端已构建
cd D:\XUYIFEI\XUPROJECTS\msdsfullstack\msdsPC\ruoyi-MsdsPc-react\react-ui
npm run build:prod

# 2. 检查构建产物
dir dist

# 3. 检查Docker配置
cd D:\XUYIFEI\XUPROJECTS\msdsfullstack\msdsdocker
dir docker-compose.prod.yml
dir .env.prod
```

### 步骤2：连接服务器

```bash
# SSH连接到服务器
ssh root@39.107.211.72

# 创建项目目录
mkdir -p /opt/msds /opt/msds-backup
chown -R root:root /opt/msds
```

### 步骤3：上传项目文件

```powershell
# 在本地Windows机器上执行：

# 1. 上传Docker配置
cd D:\XUYIFEI\XUPROJECTS\msdsfullstack
scp -r msdsdocker root@39.107.211.72:/opt/msds/

# 2. 上传前端构建产物
scp -r msdsPC\ruoyi-MsdsPc-react\react-ui\dist\* root@39.107.211.72:/opt/msds/msdsdocker/nginx/html/

# 3. 上传SSL证书（如果本地有）
scp flymsds.cn.pem root@39.107.211.72:/opt/msds/msdsdocker/nginx/ssl/
scp flymsds.cn.key root@39.107.211.72:/opt/msds/msdsdocker/nginx/ssl/
```

### 步骤4：配置服务器环境

```bash
# 在服务器上执行：

cd /opt/msds/msdsdocker

# 1. 设置文件权限
chmod +x deploy.sh backup-restore.sh
chmod 600 nginx/ssl/flymsds.cn.key
chmod 644 nginx/ssl/flymsds.cn.pem

# 2. 检查环境变量配置
cat .env.prod

# 3. 检查Docker配置
docker-compose -f docker-compose.prod.yml config
```

### 步骤5：执行部署

```bash
# 在服务器上执行：

cd /opt/msds/msdsdocker

# 1. 执行自动化部署脚本
./deploy.sh

# 或者手动执行：
# 停止旧容器
docker-compose -f docker-compose.prod.yml down

# 拉取最新镜像
docker-compose -f docker-compose.prod.yml pull

# 启动新容器
docker-compose -f docker-compose.prod.yml up -d

# 等待服务启动
sleep 30

# 检查容器状态
docker-compose -f docker-compose.prod.yml ps
```

### 步骤6：验证部署

```bash
# 1. 检查容器状态
docker ps

# 2. 检查服务健康状态
curl -I http://flymsds.cn
curl -I https://flymsds.cn
curl -I http://flymsds.cn/prod-api/system/user/profile

# 3. 查看日志（如有问题）
docker-compose -f docker-compose.prod.yml logs -f
```

## 🚨 常见问题及解决方案

### 问题1：容器启动失败

**症状**：容器状态显示"Exited"或"Restarting"

**解决方案**：
```bash
# 查看详细错误信息
docker-compose -f docker-compose.prod.yml logs [service_name]

# 检查配置文件语法
docker-compose -f docker-compose.prod.yml config

# 检查端口占用
netstat -tlnp | grep -E ':(80|443|3306|6379|8080)'

# 重新启动服务
docker-compose -f docker-compose.prod.yml restart [service_name]
```

### 问题2：数据库连接失败

**症状**：后端日志显示数据库连接错误

**解决方案**：
```bash
# 检查数据库容器状态
docker exec msdsmysql mysqladmin -u root -p ping

# 检查网络连接
docker exec msdsbackend ping msdsmysql

# 检查数据库配置
docker exec msdsmysql mysql -u root -p -e "SHOW DATABASES;"

# 重置数据库密码
docker exec msdsmysql mysql -u root -p -e "ALTER USER 'msds_user'@'%' IDENTIFIED BY 'new_password';"
```

### 问题3：SSL证书问题

**症状**：HTTPS访问显示证书错误

**解决方案**：
```bash
# 检查证书文件
ls -la /opt/msds/msdsdocker/nginx/ssl/

# 验证证书有效性
openssl x509 -in /opt/msds/msdsdocker/nginx/ssl/flymsds.cn.pem -text -noout

# 检查证书和私钥匹配
openssl x509 -noout -modulus -in flymsds.cn.pem | openssl md5
openssl rsa -noout -modulus -in flymsds.cn.key | openssl md5

# 重新加载Nginx配置
docker exec msdsnginx nginx -s reload
```

### 问题4：前端页面无法访问

**症状**：访问域名显示404或502错误

**解决方案**：
```bash
# 检查Nginx配置
docker exec msdsnginx nginx -t

# 检查静态文件
ls -la /opt/msds/msdsdocker/nginx/html/

# 检查Nginx日志
docker logs msdsnginx

# 重启Nginx服务
docker-compose -f docker-compose.prod.yml restart msdsnginx
```

### 问题5：API接口无法访问

**症状**：前端页面正常，但API调用失败

**解决方案**：
```bash
# 检查后端服务状态
docker logs msdsbackend

# 测试API接口
curl -I http://localhost:8080/system/user/profile

# 检查反向代理配置
docker exec msdsnginx cat /etc/nginx/conf.d/default.conf

# 重启后端服务
docker-compose -f docker-compose.prod.yml restart msdsbackend
```

## 📊 监控和维护

### 日常监控命令

```bash
# 查看所有容器状态
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

# 查看容器资源使用情况
docker stats

# 查看磁盘使用情况
df -h

# 查看内存使用情况
free -h

# 查看系统负载
top
```

### 日志管理

```bash
# 查看应用日志
docker-compose -f docker-compose.prod.yml logs -f --tail=100

# 查看特定服务日志
docker-compose -f docker-compose.prod.yml logs -f msdsbackend

# 清理日志文件
docker system prune -f
```

### 备份管理

```bash
# 备份数据库
./backup-restore.sh backup

# 备份配置文件
tar -czf /opt/msds-backup/config-$(date +%Y%m%d).tar.gz /opt/msds/msdsdocker

# 备份上传文件
tar -czf /opt/msds-backup/uploads-$(date +%Y%m%d).tar.gz /opt/msds/msdsdocker/uploads
```
