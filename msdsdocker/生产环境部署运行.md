## 🚀 手动启动生产环境命令指南

### 2. 服务器端手动启动

#### 2.1 连接到生产服务器
```powershell
ssh root@39.107.211.72
```

#### 2.2 进入部署目录
```bash
cd /opt/msds
```

#### 2.3 检查文件状态
```bash
# 查看目录内容
ls -la

# 检查JAR文件
ls -la /opt/msds/backend-build/ruoyi-admin.jar

# 检查配置文件
cat docker-compose.prod.yml
```

#### 2.4 启动服务（方式一：使用Docker Compose）
```bash
# 拉取最新镜像
docker-compose -f docker-compose.prod.yml pull

# 启动所有服务
docker-compose -f docker-compose.prod.yml up -d

# 查看服务状态
docker-compose -f docker-compose.prod.yml ps
```

#### 2.5 启动服务（方式二：逐个启动容器）
```bash
# 1. 启动MySQL数据库
docker-compose -f docker-compose.prod.yml up -d msdsmysql

# 2. 启动Redis缓存
docker-compose -f docker-compose.prod.yml up -d msdsredis

# 3. 等待数据库就绪（约30-60秒）
docker logs msdsmysql-prod

# 4. 启动后端服务
docker-compose -f docker-compose.prod.yml up -d msdsbackend

# 5. 启动前端服务
docker-compose -f docker-compose.prod.yml up -d msdsfrontend

# 6. 启动Nginx代理
docker-compose -f docker-compose.prod.yml up -d msdsnginx
```

### 7. 一键启动脚本

如果您想要一键启动，可以创建一个简单的启动脚本：

```bash
#!/bin/bash
# 文件名: start-msds.sh

echo "启动MSDS实验室管理系统..."

cd /opt/msds

echo "1. 拉取最新镜像..."
docker-compose -f docker-compose.prod.yml pull

echo "2. 启动服务..."
docker-compose -f docker-compose.prod.yml up -d

echo "3. 等待服务就绪..."
sleep 30

echo "4. 检查服务状态..."
docker-compose -f docker-compose.prod.yml ps

echo "5. 服务启动完成！"
echo "访问地址: https://flymsds.cn"
```

使用方法：
```bash
chmod +x start-msds.sh
./start-msds.sh
```
