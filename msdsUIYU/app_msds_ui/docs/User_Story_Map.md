# 用户故事地图 (User Story Map) - MSDS 管理文件系统

## 1. 用户故事地图概述

本用户故事地图旨在通过可视化方式，展现“MSDS 管理文件系统”的用户活动、用户任务以及具体的用户故事。它帮助团队从用户视角理解产品功能，梳理用户流程，并为版本规划和迭代提供依据。地图的横向代表用户的主要活动流 (User Activities)，纵向则分解为具体的用户任务 (User Tasks) 和更细粒度的用户故事 (User Stories)。

**核心用户角色**: 
-   **科研人员 (Researcher)**: 主要使用系统查阅MSDS，获取安全信息。
-   **实验室管理员 (LabAdmin)**: 主要负责MSDS的上传、管理、维护和用户权限分配。

## 2. 用户活动流 (横向骨干 Backbone)

| 用户活动 (User Activities) | 平台 (主要) | 目标用户        |
|----------------------------|-------------|-----------------|
| **1. 移动端快速访问与交互**  | 小程序      | Researcher      |
| **2. MSDS 信息获取与分享** | 小程序      | Researcher      |
| **3. 后台数据与系统管理**    | Web后台     | LabAdmin        |
| **4. 用户与权限配置**      | Web后台     | LabAdmin        |
| **5. 扩展功能与集成**      | Web后台/小程序 | LabAdmin, Researcher |

## 4. 故事优先级与版本映射 (Release Planning)

*(此部分通常在地图上通过泳道或颜色标记来直观表示每个故事所属的发布版本。以下为文字示意)*

### Release 1: MVP (V1.0)
- **核心主题**: 聚焦小程序核心体验，实现“扫码-查阅-分享”闭环，并提供基础后台管理能力。
- **包含的用户故事 (P0为主)**:
    - **小程序端:**
        - (1.1) 扫码快速查阅
        - (1.2) 小程序授权登录
        - (2.1) 关键词搜索
        - (2.2) 优化移动端预览
        - (2.4) 分享MSDS
    - **Web后台:**
        - (3.1) 上传与管理MSDS
        - (3.4) 分类与标签管理
        - (3.5) 生成并管理二维码
        - (4.1) 管理后台用户

### Release 2: V1.1 (MVP 优化)
- **核心主题**: 提升搜索与预览体验，补充基础管理功能。
- **包含的用户故事 (P1为主)**:
    - (2.1) 搜索MSDS (模糊搜索)
    - (2.1) 搜索MSDS (标签/分类筛选 - 基础)
    - (2.2) 查看搜索结果 (排序)
    - (2.3) 预览MSDS内容 (内部文本搜索)
    - (3.3) 编辑MSDS元数据 (自定义分类/标签 - 基础)
    - (3.7) 查看MSDS操作日志 (基础)

### Release 3: V2.0 (功能完善)
- **核心主题**: 完善管理流程，增强协作与合规性，提升系统健壮性。
- **包含的用户故事 (P0, P1为主)**:
    - (1.2) 忘记密码
    - (2.1) 高级搜索
    - (2.5) 收藏常用MSDS
    - (2.6) 查看MSDS版本历史
    - (3.2) 批量上传MSDS
    - (3.4) 管理MSDS版本 (完善)
    - (3.5) 删除/归档MSDS
    - (3.6) 设置MSDS复审/过期提醒
    - (3.7) 查看MSDS操作日志 (完善)
    - (4.2) 管理用户角色 (完善)
    - (4.3) 分配用户权限 (完善)
    - (5.1) 查看系统状态与日志
    - (5.2) 数据备份与恢复
    - ... (及其他V2.0规划的故事)

*(后续版本的故事映射以此类推)*
